# 重返未来1999 写作逻辑与防幻觉指南

## 技能定位

本指南专门针对高幻觉率模型（尤其是 Google Gemini 3.1 Pro 等）在写作《重返未来1999》内容时的高频错误。当模型出现"没逻辑、OOC、不真实、没味道、串台、画蛇添足、长文压缩"等问题时，使用本指南纠正。

## 一、模型写作的七大通病（必须逐条检查）

### 通病1：全知视角心里话直接吐露

**错误表现**：直接写"她感到深深的悲伤""他的内心充满了矛盾""她意识到这很重要"——把角色的内心活动直接倒给读者，没有通过行动/意象/对话/沉默传达。

**为什么错**：1999的文本是"克制的诗意"，情感从来不说出来，而是通过看得见摸得着的细节泄露。直接吐露内心=把答案塞给读者=没有味道。

**错误示例**：
"维尔汀看着暴雨，心里充满了对过去的怀念和对未来的恐惧。"

**正确示例**：
"维尔汀站在窗边，看着雨滴从地面升起。她没有说话，只是把手放在手提箱的锁扣上，轻轻转了一圈，又转回来。"

**检查清单**：
- [ ] 角色的情感是通过"做了什么"而非"想了什么"表达的？
- [ ] 有没有"感到/意识到/明白/知道/心想/内心"这类直接心理动词？
- [ ] 删掉这句心理描写，读者还能从动作/对话中读懂情绪吗？

### 通病2：前后逻辑断裂

**错误表现**：
- 上一段角色在A地，下一段突然在B地，没有转场
- 角色前一句话说不知道，后一句话就知道了所有前因后果
- 时间线错乱（刚才还是白天，突然就夜里了）
- 因果关系断裂（角色莫名其妙做了某事，没有动机铺垫）

**为什么错**：模型生成长文时注意力漂移，前面写过的设定后面忘了。这是"没有脑子的写作"的核心。

**正确做法**：
1. **写前先列因果链**：这个角色为什么要出现在这里？他下一步做什么？为什么？
2. **保持上下文一致性**：每个场景前快速回顾"角色在哪、什么时间、知道什么、不知道什么"
3. **转场必须明确**：地点变化要有交代（"他们离开了会客室，穿过走廊"）
4. **信息差管理**：角色只能知道剧本允许他知道的。别让一个从没去过南极的角色突然提起南极的细节。

**检查清单**：
- [ ] 每个角色知道他该知道的，不知道他不该知道的？
- [ ] 时间线连续吗？（用具体参照物：太阳、灯、季节）
- [ ] 每个行动都有动机吗？
- [ ] 场景之间有转场交代吗？

### 通病3：OOC（角色不还原）

**错误表现**：
- 所有角色说话都是一个调子（都像AI在说话）
- 角色做了不符合性格的事（冷静的维尔汀突然大哭，正式的十四行诗突然说脏话）
- 角色知道了不该知道的"meta"信息

**正确做法**：
1. **写前加载角色档案**：性格、说话风格、禁忌、关系网络
2. **每个角色一个"声线"**：维尔汀短句少言、十四行诗正式完整、星锑大声摇滚、37用数字、葛天文言克制
3. **用标志性用语锚定**：但不要滥用（每段都用"HELLO——"就腻了，一篇文章用1-2次足矣）
4. **检查角色禁忌**：这个角色绝对不会说的/做的，写了就是OOC

**检查清单**：
- [ ] 遮住角色名，光看对话能猜出是谁吗？
- [ ] 角色做了违反他核心矛盾的事吗？
- [ ] 角色说了违反禁忌的话吗？
- [ ] 标志性用语用过头了吗？

### 通病4：不真实 + 特殊味道丢失

**错误表现**：
- 描写空洞（"周围弥漫着神秘的气息"）
- 没有时代细节（1960s伦敦和1920s芝加哥写得一模一样）
- 角色说话像现代人（1910年的维也纳贵妇说"这个方案需要优化"）

**正确做法**：
1. **时代细节锚定**：服装、交通、通讯、饮食、社会规则都要符合时代
   - 1910s维也纳：马车、电报、咖啡馆、繁复裙装、皇室
   - 1920s芝加哥：禁酒令、爵士乐、地下酒吧、黑帮、福特汽车
   - 1960s伦敦：披头士、迷你裙、摇滚、殖民时代余晖
   - 1980s旧金山：海特街嬉皮、同性恋解放、科技萌芽
2. **语言时代感**：角色用词符合其时代和阶层，不用现代流行语
3. **神秘学家的社会地位**：不同时代神秘学家处境不同——被猎巫、被收容、被利用、被隐瞒。写清楚角色在社会中的位置

**检查清单**：
- [ ] 这个场景放在哪个年代读者能明确感知吗？
- [ ] 角色会说"这个方案需要优化"这种现代职场话吗？
- [ ] 角色的穿着/出行/通讯方式符合时代吗？
- [ ] 神秘学家在这个时代的社会地位是什么？

### 通病5：游戏机制串台（把系统术语当剧情语言）

**错误表现**：
- 角色对话里说"我的灵感是智系""我要释放至终的仪式""叠加燃烧层数"
- 旁白写"她的灵感属性是星"
- 战斗描写用游戏数值（"造成200%现实创伤"）

**为什么错**：灵感、创伤、咒语阶次、狂想、塑造、共鸣——这些是**游戏机制**，不是**剧情语言**。游戏里的角色从不会说"我的灵感是XX"。他们用的是神秘术、歌谣、咒语、仪式这些"戏内"词汇。

**正确做法**：
- 戏内词汇（剧情里会说）：神秘术、咒语、仪式、魔精、神秘学家、暴雨、回溯、术式、灵媒、占卜、通灵
- 戏外词汇（剧情里不会说）：灵感（星木兽岩智灵）、创伤（现实/精神）、至终的仪式、塑造、狂想、共鸣、心相、咒语阶次、激情条、暴击、穿透、debuff/buff

**对照表**：
| 戏外（不要用） | 戏内（要用） |
|---|---|
| 我的灵感是智 | 我是个神秘学家/我擅长通灵/算数 |
| 释放至终的仪式 | 吟诵咒语/唱起歌谣/举行仪式 |
| 造成精神创伤 | 刺痛他的心智/搅乱他的神志 |
| 叠加燃烧层数 | 火焰越烧越旺 |
| 狂想/塑造 | 力量觉醒了/境界突破了（也要少用） |
| 暴击/穿透 | 一击致命/直透心魄 |

**检查清单**：
- [ ] 文中有游戏数值吗？（XX%伤害、XX层数、XX点）
- [ ] 角色对话里有游戏术语吗？（灵感、创伤、狂想、塑造、共鸣）
- [ ] 战斗描写是"叙事化"而非"数据化"吗？

### 通病6：画蛇添足的强调（meta式废话）

**错误表现**：
- "在这片被暴雨冲刷的土地上……"（每次场景都强调暴雨）
- "这不是游戏，这是真实的世界……"（特意向读者强调）
- "这意味着，神秘学家在这个世界是被……"（用评论腔解释设定）
- 把世界观设定当作"知识点"生硬插入剧情

**为什么错**：这些是AI"自我意识过剩"的产物——AI觉得需要向读者证明"我知道这是架空世界"或"我在给你讲设定"。真正的好作品是**顺其自然展示**，不是**停下来解释**。

**正确做法**：
1. **展示而非解说**：世界观通过角色遭遇、对话、环境细节自然流露
   - 错："神秘学家在这个世界受到歧视。"
   - 对："掌柜的看见她袖子下的符纹，笑容收了收，铜板数了三遍才找给她。"
2. **暴雨是背景不是主角**：写一篇故事不需要每个段落都提暴雨。暴雨只在它影响剧情时才出现。
3. **禁用meta式强调**：以下句式全部禁用——
   - "这不是游戏/这不是梦境/这是真实的世界"
   - "在这个充满神秘学的世界里"
   - "这意味着/这说明了/由此可见"
   - "作为神秘学家/作为一个被收容者"

**检查清单**：
- [ ] 有没有停下来"解释设定"的段落？（删掉它，让角色演出来）
- [ ] 暴雨提了几次？如果超过剧情需要，删
- [ ] 有没有"这不是游戏"式的meta强调？

### 通病7：长文压缩（字数多就省略内容）

**错误表现**：
- 用户要求写3000字，只写了800字
- 关键场景一句话带过（"他们经历了激烈的战斗"）
- 人物心理、环境细节、对话全被压缩成干巴巴的梗概
- 前面铺垫了伏笔，后面忘了回收
- 剧情跳跃（从事件A直接跳到事件C，B没了）

**为什么错**：高幻觉模型在长生成时倾向于"总结"而非"展开"，用梗概糊弄字数。这导致文章"没有逻辑、没有智商、没有文笔味道"。

**正确做法**：
1. **字数拆解**：写3000字前，先列3000字的结构（开场500 + 冲突800 + 高潮800 + 收尾500 + 细节400），每段标注写什么
2. **一个场景一个场景写**：不要试图一口气写完，每个场景单独展开（环境+动作+对话+内心暗示）
3. **对话填充细节**：对话是最自然的展开方式，让人物说细节，不要用旁白总结
4. **拒绝梗概句**：出现"他们进行了激烈的战斗""时间过得很快""经过一番波折"这类概括句，必须展开成具体场景
5. **伏笔回收表**：写前列伏笔清单，写后逐条核对是否回收

**检查清单**：
- [ ] 有没有一句话带过本该展开的场景？
- [ ] 有"经过一番波折""时间过得很快"这类梗概句吗？
- [ ] 写前列的结构，每段都写到位了吗？
- [ ] 伏笔都回收了吗？

## 二、防幻觉铁律（索引优先，禁止凭印象）

**铁律1：角色信息必须来自数据，禁止编造**
- 角色的年龄、经历、关系、说话风格——全部来自 `data/skill_03`、`data/skill_04`、`data/角色/`、`data/角色列表/`
- 不确定就说"资料中没有提到"，不要脑补
- 特别小心：不要给角色编造没发生过的剧情

**铁律2：剧情必须来自数据，禁止发明**
- 主线章节内容来自 `data/skill_02` 和 `data/主线/`
- 支线来自 `data/skill_05` 和 `data/支线/`
- 引用具体剧情时必须核对原文，不能凭印象改写

**铁律3：专有名词拼写必须精确**
- 圣洛夫基金会、重塑之手（Manus Vindictae）、拉普拉斯科算中心、芝诺军备学院、阿派朗学派
- 维尔汀（司辰）、十四行诗、星锑、苏芙比、37、伊索尔德、卡卡尼亚
- 暴雨、回溯、流溢、霍夫曼结、平衡伞、手提箱、纺车
- 写错专有名词=最严重的幻觉

**铁律4：搜索优先，记忆靠后**
- 需要具体信息时，先用 `scripts/query.sh` 或 `search_index.py` 搜索原始数据
- 搜索结果优先于模型记忆
- 模型记忆可能包含幻觉，数据文件不会

**铁律5：时代背景必须准确**
- 不确定某年某地的历史细节，宁可模糊处理也不要编造
- 例如：不确定1910年维也纳的街道细节，写"她穿过一条老城区的小巷"就够，不要硬编"路过圣斯蒂芬大教堂"除非确定

## 三、写作质量自检流程（每次写作完成后执行）

1. **逻辑检查**：时间线连续吗？因果链完整吗？角色动机清楚吗？
2. **OOC检查**：每个角色的对话符合其性格吗？遮住名字能猜出是谁吗？
3. **时代检查**：年代/地点/社会状态准确吗？
4. **机制检查**：有游戏数值/系统术语混入剧情吗？
5. **meta检查**：有"这不是游戏""这意味着"式的废话吗？
6. **压缩检查**：有梗概句吗？该展开的都展开了吗？
7. **幻觉检查**：角色/剧情/专有名词都来自数据吗？有编造的吗？
8. **味道检查**：情感克制吗？有具体意象吗？有时代细节吗？

## 四、正确的写作提示词模板

### 通用模板（写作前加载）

```
写作《重返未来1999》同人，必须遵守：
1. 情感克制：角色情绪通过行动、对话、意象、沉默表达，绝不直白吐露内心
2. 时代还原：写清楚【年代+地点+社会状态】，服装/交通/语言符合时代
3. 戏内语言：用神秘术/咒语/仪式/神秘学家等剧情词汇，禁用游戏机制术语（灵感/创伤/狂想/塑造/暴击/穿透）
4. 角色还原：每个角色按数据档案的说话风格，禁止OOC
5. 禁止meta：不写"这不是游戏""这意味着"等解释性废话
6. 完整展开：禁止梗概句，每个场景充分展开环境/动作/对话
7. 防幻觉：角色/剧情/专有名词全部来自数据文件，不编造
```

### 角色写作模板

```
扮演【角色名】写一段【场景】。
角色档案：data/skill_03_角色百科A.md 中【角色名】条目
说话风格：参考 data/skill_11_角色语音风格库.md（如有）
登场剧情：参考 data/skill_16_角色登场索引.md（如有）
时代背景：本场景发生在【年代+地点】，注意【该时代社会状态】
要求：严格按角色说话风格，情感克制，禁用游戏机制术语，不解释设定
```

## 五、Gemini 系列特别警示

Google Gemini 3.1 Pro 等模型在写作本作内容时，以下错误频率特别高，**写后必须逐条检查**：

- [ ] 有没有"全知视角内心独白"？（"她心中充满了……"）
- [ ] 有没有编造剧情/角色经历？（凭印象编，实际没发生）
- [ ] 有没有把灵感/创伤/狂想/塑造当剧情语言？（"她的灵感是智系"）
- [ ] 有没有meta式强调？（"这不是游戏""这意味着"）
- [ ] 有没有每段都提暴雨？（暴雨是背景不是主角）
- [ ] 有没有长文压缩成梗概？（写3000只给800）
- [ ] 有没有角色说话像现代AI？（"整体而言""值得注意的是"）
- [ ] 有没有专有名词拼错？（基金会/重塑之手/角色名）
