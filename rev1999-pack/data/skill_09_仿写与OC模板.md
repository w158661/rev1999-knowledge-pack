### 仿写技巧总纲

【核心原则】重返未来1999的文本不是"讲故事"，而是"呈现一个世界"。游戏文本拒绝直接告诉读者角色的感受，而是通过动作、环境、对话的细节让读者自己感受。这是所有仿写的起点。

【叙事风格模仿的三步法】

第一步：确定时代背景。
不同的时代有不同的语言风格。1990年代苏联的文本带有革命浪漫主义和工业质感，1910年代维也纳的文本带有华丽和阴郁的世纪末氛围，唐代风格的中国故事带有文白夹杂的古典韵味，1960年代美国西海岸的文本带有街头和摇滚的粗粝感。仿写前必须确定：角色生活在什么年代、什么地点、什么社会阶层，这决定了人物说话的方式和叙事者观察世界的角度。

第二步：确定叙事视角。
游戏主要使用第三人称旁白，但视角的"距离"可以调节。近距离视角大量描写角色的内心活动和细微动作，适合心理描写密集的角色（如伊索尔德、卡卡尼亚）。中距离视角描写角色的可见动作和外界环境，适合行动导向的角色（如J、玛尔纱）。远距离视角像观察者一样记录，适合神秘感强的角色（如葛天、37）。多视角切换可以在不同角色间建立对比和张力。

第三步：确定情感基调。
游戏文本的情感表达极度克制，从不直接说"他感到悲伤"，而是通过动作和环境来暗示。克制型基调适合军人、学者类角色（如伊戈尔、北方哨歌），用沉默和细节表达情感。热烈型基调适合年轻、热情的角色（如可燃点、芭卡洛儿），用感叹号和短促有力的句子。冷静型基调适合理性、超然的角色（如37、洛伦兹蝴蝶），用数据和精确描述。混乱型基调适合精神状态不稳定的角色（如伊索尔德、卡卡尼亚），用意识流和跳跃的意象。

【游戏文本的五大特征】

特征一：句子的节奏感。
游戏文本的句子长短交替，形成独特的韵律。短句用于动作和关键信息，如"J转身跳向临近的大楼。此时腾空而起的双腿却被赶忙扑上来的另一股力量抓住。"长句用于环境和氛围，如"这是一张带有关切神色的脸，在皱纹中似乎还藏有少许疑虑。"整段文字有起有伏，不会全是长句也不会全是短句。仿写时要控制句子的呼吸感，长句之后接短句，像呼吸一样自然。

特征二：意象的选用。
游戏文本使用具体而非抽象的意象。不说"她的心情很沉重"，而说"她感到一阵炫目与刺痛"。不说"时间过去了很久"，而说"两年后的杏花在同一刻盛开"。意象来源于角色的生活环境和时代背景——苏联角色用雪原、钢铁、奶酪，中国古典角色用白屋、黑瓦、杏花，拉美角色用迷宫、镜子、沙漠。仿写时要找到属于角色世界的具体意象，避免使用通用的抽象表达。

特征三：情感的表达。
游戏文本的情感表达极度克制。不从外部描述角色的感受，而是让读者通过角色的动作、对话和环境描写来推断。不说"她很悲伤"，而是写"她只是低下头，轻轻地啃咬着自己的手指"或"北方哨歌撕开包装，却只轻轻咬了一小口"。不说"他愤怒了"，而是写"那两颗石子震颤着，像是兔子腔内两枚鼓胀、湿润又赤红的卵巢"。情感通过意象和动作传达，而非直接陈述。

特征四：对话的写实。
每个角色的对话都符合其性格、时代背景和教育水平。军人说话简洁命令式（伊戈尔："不要回头，向前跑"），学者说话正式学术化（北方哨歌："从雪白，到银灰……这里给人的感觉比来亚什基更冰冷"），街头人物说话粗犷口语化（J："想跟我比划比划？"），古代人物说话文绉绉（葛天："天下之大，事物亦繁多。不足为奇"）。对话中不使用不符合角色身份的语言，即使是在翻译腔浓厚的游戏中，每个角色的语言风格也保持一致性。

特征五：描述的精确。
游戏文本的描述有强烈的时代感和具体性。不是泛泛地说"街上很热闹"，而是写"绸缎悬街而过，红石榴和胡桃累成小塔，麻饼在土坑里焙出喷香的滋味"。不是抽象地说"她很优雅"，而是写"女士的扇子扑扑扇动，手帕上绣着淡紫色的鸢尾花"。描述性的语言要有具体的细节，让读者能在脑海中构建出完整画面。


### 仿写模板

【模板1：维尔汀式叙事】

特征：简洁、冷峻、偶尔的诗意。叙事者像一个沉默的观察者，只记录必要的信息，但在关键处会突然流露出诗意。

句式结构：短句为主，用句号分割思考。环境描写一句，动作描写一句，内心感受若有若无地穿插一两句。不使用感叹号，节制使用逗号。

节奏控制：句子短促有力，很少超过30个字。段落也短，通常3-5句就换段。在关键情节处句子会变得更短，几乎像在喘息。

适用场景：游戏主线剧情、标题画面文本、箱中记录。

示例：
[环境描写，一句]。[动作描写，一句]。[观察，一句]。[内心感受，若有若无的一两句]。

实操模板：
[名词] + [动词] + [副词/介词短语]。
[主语] + [动作] + [对象]。
[主语] + [状态] + [仿佛/如同] + [意象]。

【模板2：十四行诗式叙事】

特征：正式、礼貌、略带书卷气。叙事者受过良好教育，用词准确但不华丽，逻辑清晰，像在读报纸或写报告。

句式结构：完整句子，逻辑清晰，使用"因为""所以""虽然""但是"等连接词。句子结构完整，很少使用省略和断裂。

修饰风格：使用适度的形容词，但不过分华丽。喜欢用"似乎""也许""可能"等不确定词，体现角色的谨慎性格。

适用场景：新角色登场介绍、基金会档案记录、任务简报。

示例：
[正式问候]。[观察到的事实]。[自己的感受，用"也许"开头]。

实操模板：
[尊称] + [礼貌性问候]。
[观察到的事实] + [逻辑推断]。
[个人感受] + [但/不过] + [理性修正]。

【模板3：星锑式叙事】

特征：热情、夸张、摇滚风、英语混搭。叙事者永远在情绪的顶点，语言像音乐一样有节奏，感叹号密集。

句式结构：短促有力，像在打碟。大量使用感叹号、破折号、英语单词混搭。句子经常以HELLO、YEAH、OH等感叹词开头。

节奏控制：语速快，节奏跳跃，思维发散。从一个话题跳到另一个话题，中间用感叹号连接。

适用场景：活动剧情、轻松搞笑场景、角色语音。

示例：
HELLO——！[热情的招呼]！[当前状况的描述，用摇滚术语]！[行动号召]！

实操模板：
[感叹词/英语] + [感叹号]。
[摇滚/音乐相关比喻] + [感叹号]。
[行动号召/反问] + [感叹号]。

【模板4：37式叙事】

特征：数学化、精确、不带感情。叙事者用数字和逻辑描述一切，省略了所有修饰词和情感表达。

句式结构：陈述句为主，像在宣读定理。每句话都包含一个明确的事实或逻辑判断。不使用比喻（除非是数学比喻）。

修辞方式：用数字量化一切，把抽象概念转化为可计算的问题。"游戏"等于"数字的比较"，"友谊"等于"质数的无限性"。

适用场景：阿派朗学派相关剧情、理性角色独白。

示例：
[数据化的观察]。[数学化的结论]。[概率意义上的建议]。

实操模板：
[数字] + [行为/现象] + [结果]。
[众所周知] + [数学定理] + [类比到当前情况]。
[结论] + [语气词] + [进一步追问]。

【模板5：中国古典式叙事（葛天、程和光、曲娘）】

特征：文言色彩、简练、意象化。叙事者像古代文人，用最少的字传递最丰富的画面和情感。

句式结构：四字短语、对仗、省略主语。大量使用"之""乎""者""也"等文言虚词，但不过分，保持现代读者能理解的程度。

意象系统：使用中国古典意象——槐树、溪水、山风、羽毛、白屋、黑瓦、雪、梅、杏花、酒、竹。每个意象都有其文化内涵。

适用场景：中国背景角色故事、古代章节。

示例：
[环境描写，四个字]。[动作，四个字]。[对话，简洁]。[内心，四个字]。

实操模板：
[四字短语] + [环境描写]。
[主语省略] + [动作/状态]。
[引经据典] + [个人态度]。

【模板6：苏联式叙事（北方哨歌、伊戈尔）】

特征：正式、略带沉重、理想主义。叙事者带着革命浪漫主义的色彩，既有钢铁般的硬度，又有对理想社会的向往。

句式结构：长句与短句交替，长句用于描述理想和信念，短句用于描述现实和行动。带有"同志"式称呼，体现集体主义精神。

情感基调：外表克制、内心热烈。角色在公众场合保持冷静，但在独处时流露出深藏的情感。理想主义被现实打压，但从未熄灭。

适用场景：苏联/东欧背景角色、革命战争题材、理想主义者的故事。

示例：
[同志式的称呼]。[对现状的描述]。[对理想的坚持]。[行动]。

实操模板：
[称呼+同志] + [现状描述]。
[但是/然而] + [理想/信念]。
[动作] + [环境烘托]。

【模板7：拉美魔幻现实主义式叙事（虚构集、卡卡尼亚、伊索尔德）】

特征：繁复的修饰、超现实意象、内心独白。叙事者像在梦中写作，真实与虚幻的界限模糊。

句式结构：长句嵌套，意识流段落。句子可以很长，包含多个从句和插入语。意象层层叠加，像迷宫一样复杂。

意象系统：使用镜子、迷宫、门、影子、面具、舞台等象征性意象。现实事件和超现实意象交织在一起，难分彼此。

适用场景：心理描写密集的角色、精神状态不稳定的角色、拉丁美洲背景的故事。

示例：
[超现实的意象]。[现实的细节]。[两者的交织]。[揭示或顿悟]。

实操模板：
[感觉/幻觉] + [如同/仿佛] + [超现实意象]。
[现实事件] + [内心独白] + [自由联想]。
[意象叠加] + [情感爆发/顿悟]。

【模板8：西部/街头式叙事（J、阿尔古斯）】

特征：快节奏、口语化、动作感强。叙事者像动作片导演，用简短的句子和快速的场景切换制造紧张感。

句式结构：短句为主，大量动作描写。对话推进剧情，不废话。比喻直接有力，带有街头风味。

语言风格：使用俚语、口语化表达，符合角色社会阶层。对话中经常出现挑衅和嘲讽。叙事节奏快速，像拳击比赛。

适用场景：动作场面、犯罪题材、街头角色。

示例：
[动作描写，短促]。[环境描写，一句]。[对话，挑衅]。[动作/反应]。

实操模板：
[主语] + [动作] + [如同/像] + [街头比喻]。
[对话] + [语气词] + [挑衅/幽默]。
[场景切换] + [快速推进]。

【模板9：英伦/维多利亚式叙事（纸信圈儿、灯倌、笃笃骨）】

特征：细腻的阶级描写、礼貌表面下的暗流。叙事者对英国社会的阶级差异有敏锐的观察。

句式结构：语言礼貌但暗藏锋芒，对话中有大量潜台词。环境描写充满工业化细节。

情感基调：表面克制，内心汹涌。角色用礼貌的语言掩盖真实情感，但细节会暴露真相。

适用场景：英国背景角色、维多利亚/爱德华时代故事。

示例：
[礼貌用语]。[表面上的观察]。[动作/细节，暗示真实情感]。

实操模板：
[敬语/礼貌用语] + [表面信息]。
[但/不过] + [暗示/潜台词]。
[细节描写] + [阶级/社会背景暗示]。

【模板10：儿童文学/童话式叙事（回声谣、野树莓、数羊羔）】

特征：简单、温柔、带有童话色彩。叙事者用孩子的视角看待世界，语言简单但蕴含深意。

句式结构：句子短而简单，像在唱歌。使用重复和韵律，营造童话感。对话中充满语气词和拟声词。

情感基调：温柔中带着悲伤，纯真中透着深刻。表面是童话，内核是成长与失去。

适用场景：童话背景角色、儿童视角的故事、治愈系剧情。

示例：
[轻柔的问候]。[简单的观察]。[重复/韵律]。[温暖/悲伤的揭示]。

实操模板：
[语气词] + [简单陈述]。
[重复性句式] + [韵律感]。
[童话式的解释] + [深层含义]。

【模板11：军事/战争式叙事（伊戈尔、莫莉德尔、玛尔纱）】

特征：简洁、精确、命令式。叙事者像战地记者，用最少的字传递最残酷的信息。

句式结构：命令式短句，大量使用时间和数字精确描述。对话简短，沉默和动作承担大量叙事功能。

情感基调：表面坚硬，内里柔软。角色在战场上冷酷，但在回忆和独处时流露出情感。战争场景描写富于画面感。

适用场景：战争背景故事、军人角色、军事行动描写。

示例：
[时间/地点，精确]。[命令/行动]。[观察/反应]。[沉默/内心]。

实操模板：
[数字/时间] + [精确描述]。
[命令式短句] + [动作]。
[沉默] + [内心/回忆] + [克制的情感]。

【模板12：侦探/悬疑式叙事（梅兰妮、阿尔古斯、梁月）】

特征：逻辑严密、伏笔精巧、逐步揭示。叙事者像侦探一样收集线索，拼图式地展现真相。

句式结构：叙事在调查和回忆之间切换，每段对话都包含关键信息。心理描写和战略思考穿插其中。

节奏控制：张弛有度，调查场景信息量大，动作场景紧张刺激。伏笔在前文埋下，在后文揭晓。

适用场景：破案剧情、悬疑故事、智斗场面。

示例：
[线索/观察]。[推理/联想]。[行动/验证]。[揭示/反转]。

实操模板：
[发现] + [疑问] + [推理]。
[假设] + [验证] + [反转/确认]。
[伏笔回收] + [真相揭示]。


### OC创作高级模板

【OC设计九步法】

第一步：确定灵感。
游戏有六个灵感：星、木、兽、岩、智、灵。每个灵感对应不同的性格倾向和行为模式。星灵感对应热情、理想主义，适合领导者和开拓者。木灵感对应坚韧、生命力，适合成长型角色和守护者。兽灵感对应野性、本能，适合直觉型角色和战士。岩灵感对应稳重、坚韧，适合防御型角色和坚守者。智灵感对应理性、智慧，适合学者型角色和策略家。灵灵感对应神秘、超自然，适合通灵者、神秘学家和异类。选择灵感时考虑角色的核心特质，同时灵感和角色名之间应有某种隐喻关联。

第二步：设计核心矛盾。
用一个简洁的句子概括角色的内心冲突。这是角色所有行为的驱动力。核心矛盾必须存在于角色内部，而非外部环境。一个角色如果没有核心矛盾，就没有成长弧线。例如伊戈尔的核心矛盾是"既是必须为士兵生命负责的将军，又是被上级命令束缚的棋子"。笃笃骨的核心矛盾是"用愤怒和尖刻包裹的脆弱，渴望被理解但拒绝被接近"。无名者的核心矛盾是"可以作为任何人，因此没有一个人真正属于自己"。核心矛盾应该来自角色的背景故事，而非凭空设定。

第三步：绑定时代背景。
游戏的角色都绑定在"暴雨"之前的具体历史时期和地点。时代和地点不仅仅是背景设定，它决定了角色的语言、穿着、价值观和困境。需要选择具体的年份而不是模糊的"近代"，具体的地点而不是泛泛的"欧洲"。例如"1912年维也纳"而不是"20世纪初的欧洲"，"1975年旧金山海特街"而不是"美国西海岸"。时代背景应与角色的核心矛盾相互呼应——角色的困境是那个时代特有的困境。

第四步：设计时代感外观。
角色的穿着必须符合时代，但要有个人特色。服装细节反映角色的性格、社会地位和职业。例如葛天是古装羽翼，体现其非人身份和古典气质。北方哨歌是苏联研究员制服，体现其学术身份和时代背景。J是旧金山街头工装，体现其铸剑师身份和街头气质。服装颜色、材质、配饰都有心理暗示——红色代表热情和危险，蓝色代表冷静和理性，破损的衣物代表困境和挣扎。

第五步：命名。
角色的名字应符合文化背景，同时有隐喻意义。中国角色用中文名（葛天、曲娘、程和光），名字本身可能有古典出处。苏联/俄罗斯角色用俄语名（瓦莲京娜、伊戈尔），名字能体现民族和文化背景。英语国家角色用英文名，可以有姓氏或昵称。名字最好有隐喻含义——"37"是质数，体现角色对数学的纯粹追求。"北方哨歌"是候鸟，体现角色的迁徙和坚持。"无名者"体现角色的身份缺失。名字的翻译要考虑到中文玩家的接受度，同时保持原名的文化韵味。

第六步：设计介质。
游戏中的每个角色都有"介质"——一个反映角色核心本质的物品或概念。介质不是简单的武器或工具，而是角色灵魂的物化。例如玛尔纱的介质是"盾牌"（象征守护和牺牲），伊戈尔的介质是"冥界穿梭"（象征死亡和连接），回声谣的介质是"回声"（象征记忆和存在）。介质应该与角色的核心矛盾相关——它是角色解决矛盾的方式，也是角色困境的象征。介质的名称要简洁有力，一般由两个词组成。

第七步：设计香调。
香调是游戏独特的设定，用气味来描述角色的特质。香调由三部分组成：前调（第一印象）、中调（核心特质）、后调（内在本质）。例如伊戈尔的前调是"硝烟、雪松与皮革"（军人的外在），中调是"伏特加、桦树汁与干草"（俄罗斯的根源），后调是"铁锈、泥土与残烛"（战争与牺牲的印记）。香调要反映角色的表面性格、内在本质和命运走向。香调中的每个气味都要有合理的解释，不能随意堆砌。

第八步：写背景故事。
背景故事需要交代角色的出身、关键事件、与"暴雨"的关联，字数控制在150字以内。背景故事要包含角色的核心矛盾——一个无法解决的内心冲突。背景故事要体现"暴雨"对角色命运的影响，可以是直接导致失去，也可以是间接改变。背景故事不需要交代所有细节，留白让读者想象。游戏文本中，角色的背景故事往往是碎片化呈现的，不一次性交代完。

第九步：设计说话风格。
说话风格要符合角色的灵感和性格，同时体现时代背景和文化背景。列出3个标志性用语，体现角色的说话习惯和思维模式。说话风格和叙事风格要一致——一个理性角色不会突然用诗意的语言。说话风格要包含口头禅、语气词、句式特点等细节。例如37经常说"数字并不是越大就越好"，体现其数学化的思维方式。伊戈尔经常说"不要回头"，体现其军人的坚定和决绝。

【OC设计范例一：从灵感选择到完整设定】

灵感：星。

核心矛盾：一个从未来回到过去的科学家，她知道自己要阻止的灾难正是自己造成的，但她无法向任何人解释。

时代背景：1987年，美国加州，帕萨迪纳喷气推进实验室。

外观：灰色研究员制服，内衬有烧焦痕迹的旧T恤。左手戴一只不走的手表，时间永远停在00:00。眼镜片上有细小的裂纹，像蛛网。

命名：中文名"时苒"（意译：时间荏苒），英文代号"Chronos-7"。名字暗示时间流逝和悲剧性重复。

介质："倒数计时器"——一个显示倒计时的怀表，每当她做出改变历史的行为，数字就会减少。归零时意味着她将消失。

香调：前调是"臭氧与金属"（实验室和宇宙），中调是"旧书、咖啡与焊锡"（研究者的日常），后调是"焦糖、灰烬与冷空气"（燃烧后的余烬和时间的尽头）。

背景故事：时苒是1999年的科学家，在"暴雨"发生时被卷入时间裂隙，回到了1987年。她发现"暴雨"的根源来自一个她曾参与的研究项目——一个试图重构时间线的实验。她必须在1987年阻止这个项目的启动，但每一次干预都会让倒计时减少。她不知道归零后会发生什么，但仍然选择继续。

说话风格：说话简洁，偶尔蹦出不属于这个时代的术语。习惯性看手表，对时间极其敏感。说话时喜欢用"根据我的计算"开头，但有时会突然语塞，因为说不出口的理由。标志性用语：
"根据我的计算，你还有3分17秒可以改变主意。"
"不是未来，是过去。"
"别问了，你没时间了。"

【OC设计范例二：从灵感选择到完整设定】

灵感：兽。

核心矛盾：一个在动物园里长大的神秘学家，她能和动物说话，但无法和人类正常交流。她渴望融入人类社会，但每一次尝试都带来灾难。

时代背景：1960年，上海，法租界旧址的旧动物园。

外观：褪色的蓝布衫，袖口磨得发白。头发用橡皮筋随意扎成马尾，总是别着一根孔雀羽毛。赤脚，脚底有厚厚的茧子。手腕上系着三条不同颜色的绳子——分别代表她三只已经去世的动物朋友。

命名："阿翎"（翎，鸟类的羽毛，象征自由和飞翔）。没有姓氏，动物园的人叫她"阿翎"，不知道她父母是谁。

介质："兽语"——能与所有动物交流，但代价是逐渐失去人类的语言能力。使用神秘术时，她的眼睛会变成竖瞳。

香调：前调是"青草、动物皮毛与消毒水"（动物园的气味），中调是"雨水、铁锈与熟透的香蕉"（城市与自然的混合），后调是"桂花、泥土与旧报纸"（记忆中的上海和逐渐褪色的世界）。

背景故事：阿翎在1960年被发现于上海动物园的猴山，当时大约六岁，不会说话，只会模仿动物的叫声。她被动物园员工收养，在笼舍之间长大。她发现自己在动物面前能表达自如，但面对人类时就结巴和沉默。1966年，动物园被关闭，所有动物被转移。她试图保护一只年迈的老虎，最终失败。她第一次使用"兽语"神秘术——不是和动物说话，而是让人类听到动物内心的恐惧——但没有人相信她。

说话风格：说话断断续续，句与句之间经常有长时间的停顿。喜欢用动物来做比喻（"像老猫一样慢"、"像麻雀一样慌"）。对动物说话时语速流畅，对人类说话时语速变慢。标志性用语：
"他……像那只老猴子。不，不是。"
"你听，麻雀在说你撒谎。"
"我不用说话，我的眼睛就是竖瞳。"

【OC设计范例三：从灵感选择到完整设定】

灵感：灵。

核心矛盾：一个"不存在"的人——她在"暴雨"中失去了存在本身，所有人都会在见到她后的下一秒忘记她。她试图留下痕迹，证明自己活过。

时代背景：1995年，日本东京，新宿的地下酒吧街。

外观：黑色连衣裙，白色围裙——像酒吧女招待的制服，但永远一尘不染。头发遮住半张脸，脖子上挂着一块翻盖怀表，表盖是空的，没有照片。左手无名指戴着一枚银戒指，她自己也不知道是谁给的。

命名："零"（Zero），她自己给自己取的名字，因为她像一个零——存在但没有意义，占据空间但不被记住。代号"虚无之忆"。

介质："遗忘之痕"——她触碰过的物体会留下她的痕迹，但人无法记住她的脸。她可以用记忆换取在他人记忆中短暂存在的时间——每存在一分钟，她就会失去一段记忆。

香调：前调是"烟灰、湿报纸与地铁站的冷风"（东京夜晚的气味），中调是"栀子花、旧香水与灰尘"（被遗忘的过去），后调是"铁、海盐与空房间"（孤独和虚无）。

背景故事：零不知道自己是谁，她醒来时已经在"暴雨"之后的新宿街头。她发现自己有一个特殊的神秘术——她可以让人记住她，但代价是那个人会失去一段等长的记忆。她开始在新宿的地下酒吧工作，收集别人的记忆碎片，试图拼凑出自己的过去。她发现自己的存在与"暴雨"中的某个裂缝有关——她不是被"暴雨"带走的人，而是被"暴雨"留下的人，但"留下"的代价是"被遗忘"。

说话风格：轻声细语，像怕打扰别人。说话时经常看着对方眼睛，但对方下一秒就会忘记她的脸。她会在对话中突然插入"你还记得我吗？"然后自嘲地笑。喜欢用"没关系"来结束对话，因为她知道对方马上就会忘记。标志性用语：
"没关系，你很快就会忘记的。"
"我可以用一分钟的记忆换你一分钟的记住，要交易吗？"
"今天是我第374次介绍自己，但对你来说是第一次。"


### 常见AI写作问题与修复

【问题1：直白的情感陈述】

AI写作特征：直接使用"他感到悲伤""她很愤怒""他内心充满矛盾"等抽象的情感描述。

错误示例："伊戈尔感到深深的悲伤和自责，他无法忘记那些牺牲的士兵。"

游戏文本写法："伊戈尔没有回头。他记得每一个名字。安德烈、阿尔谢尼、格里高利——他念出这些名字时，语气像在点名。"

修复方法：删除所有"感到""觉得""认为"等情感引导词，用具体的动作、回忆、对话来表达情感。角色在悲伤时不是"感到悲伤"，而是做悲伤的事——沉默、盯着某处、重复一个动作、念出某个名字。让读者从动作中推断情感，而不是被告知情感。

【问题2：空洞的形容词堆砌】

AI写作特征：使用"神秘的""深邃的""不凡的""令人惊叹的"等空洞形容词，不提供具体信息。

错误示例："她有着深邃的眼神和神秘的气质，散发着不凡的魅力。"

游戏文本写法："她喃喃着，注视如同珠宝一般佩戴在她的额前与项上。两颗眼睛如同河堤下淤泥包裹着的灰色石头。"

修复方法：把每个形容词替换为具体的视觉描写。不是"深邃的眼神"，而是"眼睛如同河堤下淤泥包裹着的灰色石头"。不是"气质不凡"，而是"她喃喃着，注视如同珠宝一般佩戴在额前与项上"。用具体的意象代替抽象的形容词，让读者自己得出结论。

【问题3：过度的内心独白和解释】

AI写作特征：角色不断地在内心解释自己的行为动机，或者叙事者直接告诉读者角色的想法。

错误示例："她心里想：我必须完成这个任务，因为这关系到整个团队的安全。她深吸一口气，鼓起勇气推开了门。"

游戏文本写法："北方哨歌深吸一口气，一股不存在的寒风灌满了鼻腔，直抵肺的最深处。她推开了门。"

修复方法：删除"她心里想""她意识到""她明白"等引导词。角色的内心通过动作和表情来展现。如果角色必须表达内心想法，也应该是简洁的、碎片化的，而不是完整的心理分析。让读者通过角色的行为来推断其内心状态。

【问题4：缺乏时代感的语言】

AI写作特征：所有角色使用相同的现代语言风格，不分时代背景。古代人说现代话，外国人说中文网络用语。

错误示例："葛天穿越回了古代，他觉得很酷，决定要在这个世界好好生活。"

游戏文本写法："燕平微微颔首，朝老者做了个手势。'天下之大，事物亦繁多。不足为奇。'"

修复方法：研究角色所处时代的语言特点。中国古典角色使用文白夹杂的语言，避免现代词汇和网络用语。苏联角色使用正式、略带书卷气的语言。街头角色使用口语化、俚语化的表达。每个时代和地区都有其独特的语言风格，仿写时必须尊重这种风格。

【问题5：过度使用比喻】

AI写作特征：每句话都用比喻，比喻之间没有逻辑关联，纯粹为了装饰。

错误示例："她的眼睛像星星一样闪烁，她的微笑像春天一样温暖，她的步伐像风一样轻盈，她的声音像泉水一样清澈。"

游戏文本写法："那两颗石子震颤着，像是兔子腔内两枚鼓胀、湿润又赤红的卵巢。"

修复方法：宁缺毋滥。一个段落最多使用一个比喻，而且这个比喻必须服务于情感表达或氛围营造。比喻要出人意料但有道理——"两颗眼睛如同河堤下淤泥包裹着的灰色石头"之所以好，是因为它暗示了角色的阴郁和粗糙。比喻要具体、有质感，而不是追求表面的优美。

【问题6：对话不符合角色身份】

AI写作特征：所有角色的对话风格统一，上流社会的贵族和下城区的流浪汉说同样的话。

错误示例："伊索尔德说：'嘿，老兄，你还好吗？'"

游戏文本写法："伊索尔德说：'是的，卡尔先生。'——极其礼貌，用词优雅，语气平稳，极少表露真实情绪。"

修复方法：每个角色都有其独特的说话方式。上流社会角色用敬语和正式词汇，底层角色用俚语和口语，学者用学术化表达，军人用命令式语气。在写对话前，先确定角色的社会阶层、教育背景、性格特点，然后让对话反映这些因素。可以用一个简单的"角色说话风格表"来约束自己：口头禅、句式特点、用词偏好、语气词等。

【问题7：情节推进过于急切】

AI写作特征：角色刚登场就交代所有背景，故事没有铺垫，情感没有积累。

错误示例："这就是回声谣，她是一个木偶变成的鬼魂，由记忆和光凝聚而成，她的朋友小洪扎离开了她，她现在很孤独。"

游戏文本写法：回声谣的故事通过她触摸回声石进入记忆片段来逐步揭示，她的过去像碎片一样拼凑起来，读者慢慢发现她是一个木偶，有一段没有回应的等待。

修复方法：信息要逐步释放，不要一次性交代完。背景故事通过对话、回忆、闪回、环境细节来展现。角色在故事中"发现"自己的过去，而不是一开始就"知道"一切。情感也需要积累——角色先有行为，后有情感，读者先看到行为，再体会到情感。不要急于告诉读者这个角色是谁，让读者在阅读中逐步发现。

【问题8：场景描写缺乏细节】

AI写作特征：场景描写只有功能性的描述，没有感官细节，读起来像舞台说明。

错误示例："她走进了房间，房间里有一张桌子，一把椅子，窗户开着。"

游戏文本写法："她思忖着，手指反复摩挲摇篮的边缘。烛火扑朔摇曳，夜风灌入房间，吹熄了所有蜡烛。贵妇人们惊慌地涌向外出的门扉，飞扬的裙裾之间，年幼的女童重新站起身子。"

修复方法：场景描写时要调动至少三种感官。视觉（颜色、光线、形状）、听觉（声音、沉默、回声）、嗅觉（气味、香气、臭味）、触觉（温度、质感、压力）、甚至味觉。每个场景都应该有独特的氛围，而氛围来自细节——"烛火扑朔摇曳"、"夜风灌入房间"、"飞扬的裙裾"——这些细节共同构成了一个场景的质感。不要写"房间很暗"，写"烛火扑朔摇曳，影子在墙上晃动"。

【问题9：直接使用成语或俗语解释】

AI写作特征：大量使用成语、俗语、名人名言来代替具体描写，读起来像模板。

错误示例："她经历了千辛万苦，终于守得云开见月明。功夫不负有心人，她成功了。"

游戏文本写法："她哼着歌，推开了门。阳光照进来，她眨了眨眼。'成功了。'她自言自语，声音小得几乎听不见。"

修复方法：删除所有成语和俗语，用具体的场景描写来代替。不要说"千辛万苦"，写她摔了多少次、流了多少汗、脸上的伤疤和手上的茧子。不要说"守得云开见月明"，写阳光照进来时她眨了眨眼，发现自己的影子终于完整了。成语是概括，而游戏文本需要展开——把概括变成画面，把总结变成过程。

【问题10：叙事视角混乱】

AI写作特征：在同一段内从全知视角切换到角色内心，叙事者身份不明确。

错误示例："她不知道危险正在靠近。事实上，敌人已经在她身后举起了枪。她还在想今晚吃什么。她是一个善良的人，命运不该这样对她。"

游戏文本写法：叙事视角一旦确定，就保持在同一个视角内。如果从角色的视角出发，叙事者只能描述角色知道的信息。全知视角叙事者则有更大的自由度，但也要保持一致性。

修复方法：在每一段开始前确定叙事视角。如果是近距离第三人称视角，就只能描述角色能看到、听到、感觉到的东西，不能描述角色不知道的信息。如果是全知视角，也要保持一致的叙事距离——不能一会儿在角色脑子里，一会儿在天花板上。游戏文本以第三人称中距离叙事为主，叙事者像一个站在角色旁边的观察者，既能看到角色的动作，也能感受到角色的情绪，但不直接进入角色的内心。

【问题11：句式单调缺乏变化】

AI写作特征：每句话都是"主语+谓语+宾语"的相同结构，读起来像流水账。

错误示例："她走到桌子前。她拿起杯子。她喝了一口水。她放下杯子。她叹了口气。她望向窗外。"

游戏文本写法："她走到桌子前，拿起杯子，却没有喝，只是盯着水面。窗外有麻雀在叫。她放下杯子，叹了口气——这口气很长，像要把肺里的空气都挤出去。"

修复方法：长短句交替使用。短句用于动作和关键信息，长句用于描述和氛围。使用破折号、省略号、冒号来打断句子的节奏。使用倒装句、省略句、插入语来增加变化。句子主语可以变化——不总是"她"开头，可以用动作开头、环境开头、对话开头。每个句子都应该有独特的节奏，而不是机械地重复相同结构。

【问题12：情感表达过于直白或夸张】

AI写作特征：用感叹号、大写、重复来表达情感，情感力度与情节不匹配。

错误示例："她太伤心了！！！她无法接受这个事实！！！她崩溃了！！！"

游戏文本写法："她没说话。她只是坐了下来，看着窗外的雪。过了很久，她说：'请给我一杯水。'"

修复方法：情感表达要用"减法"。角色越悲伤，语言越简洁。角色越愤怒，动作越克制。在游戏文本中，最强烈的情感往往通过最安静的方式表达——长时间的沉默、一个简单的动作、一句平淡的话。感叹号用在真正需要强调的地方，不要滥用。情感的表达要留白，让读者自己去填充和感受。
