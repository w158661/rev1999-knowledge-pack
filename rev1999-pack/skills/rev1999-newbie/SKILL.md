# 重返未来1999 新手引导技能

## 技能定位

本技能是《重返未来1999》的新手入门指南，面向零基础新玩家，从最基础的"我是新玩家，我该怎么做？"开始，逐步引导至能独立完成日常和周常内容、规划资源、组建队伍的中期阶段。不涉及高难挑战和极限配队，目标是让新玩家顺利度过开荒期。

## 新玩家引导流程

### 第一步：了解世界观（3分钟速读版）

**什么是暴雨？**
暴雨是1999世界里的核心灾难。它不是普通的雨，而是从地面往天上倒流的"时间回溯雨"。被暴雨淋到的人、建筑、甚至整个时代都会被抹除，回到过去。第一场暴雨发生在1999年12月31日，之后世界不断被暴雨冲刷，时间一直倒退。

**什么是神秘学家？**
神秘学家是游戏里所有可操控角色的种族。他们天生会使用神秘术（魔法），曾经昌盛，现在衰落，被人类排挤。你抽到的每个角色都是神秘学家。

**你是谁？**
你是维尔汀，一个独一无二的"司辰"——暴雨免疫者。只有你能在暴雨中自由行走。你的任务是在暴雨中穿梭各个时代，记录时间，拯救神秘学家。你的助手叫十四行诗，一个靠谱的岩系姑娘。

**不需要了解全部背景，边玩边学。**
游戏剧情很精彩，有大量文学梗和哲学讨论，但新手阶段不需要全搞懂。跟着主线走，剧情会自然展开。记住三点就行：暴雨会抹除一切、你是唯一能免疫暴雨的人、你的任务是保护神秘学家。

### 第二步：开荒阵容推荐

**御三家（系统赠送）怎么用？**

你开局会获得三个角色，官方叫"御三家"：

- **十四行诗（岩/现实/辅助输出）**：你的第一助手，岩系，可以缴械控制敌人，同时能打能辅助。新手期绝对核心，建议优先培养到洞悉II。
- **星锑（星/精神/输出）**：摇滚海盗，星系输出，仪式伤害可观。前期当副C用，等你抽到更好的6星输出再替换。
- **苏芙比（木/现实/治疗）**：富家大小姐，木系治疗，可以回血也能叠中毒。前期唯一的治疗，一定要练。

御三家阵容的灵感是岩+星+木，刚好覆盖三系克制，前期推图够用。第四个位置根据你抽到的角色补上。

**新手期抽到谁先练？**

如果你抽到了以下角色，优先培养：

- 37（星/精神/追击/灵光）：版本常青树，从1.4版本强到3.8，抽到就是赚到，直接当主C练
- 维拉（木/精神/治疗/升阶）：版本第一治疗，还能加暴击和升阶，抽到直接替换苏芙比
- 环状水星（灵/精神/辅助/升阶）：百搭辅助，放进任何队伍都好用
- 牙仙（星/精神/治疗/净化）：开服至今依然强势的治疗，净化机制永远有用
- 伊索尔德（灵/现实/燃烧）：燃烧体系核心，抽到她就有了一个完整体系的方向
- 可燃点（兽/现实/燃烧）：燃烧体系爆发输出，配合伊索尔德很强
- 气球派对（四星/治疗）：四星战神，如果你没有6星治疗，她是你最好的选择

**不要浪费资源在哪些角色上？**

- 开服角色（红弩箭、未锈铠、温妮弗雷德等）：不是不强，而是版本更新后强度已经被超越，新手期资源紧张，不要优先投给他们
- 3星及以下角色：完全不要练，没有任何一个值得前期投入
- 没有体系配合的散件：比如你抽到了一个燃烧角色但没有伊索尔德，单独练她效果很差

### 第三步：核心玩法速通

**主线优先（推图解锁功能）**

游戏的大部分功能是锁着的，需要推主线解锁。优先级如下：

- 主线1ST-16：解锁鬃毛邮报（常驻BOSS挑战）
- 主线5TH-20：解锁雨中悬想（大型常驻挑战，也是狂想材料的来源）
- 主线关卡越往后，解锁的功能越多，体力上限也越高

建议：前期把所有体力都砸在主线上，推不动了再回头刷资源本。

**每日必做**

1. 上线收菜：荒原产出利齿子儿和微尘，记得收
2. 刷资源本：根据当前缺什么刷什么（见第四步资源规划）
3. 完成活跃度任务：每天清活跃度，拿奖励
4. 体力清空：不要攒体力，用了才会恢复
5. 魔精公司：收菜+喂食，积少成多

**每周必做**

1. 人工梦游（浅眠域）：每周刷新，必打，给大量纯雨滴和养成材料。新手期打浅眠域就够了，深眠域等练度起来再打
2. 鬃毛邮报：每周刷新，尽量打，拿纯雨滴。新手期不用追求高分，能打多少打多少
3. 雨中悬想（迷思海寻思）：每周4次扫荡，给狂想材料，记得用掉
4. 荒原资源收集：每周收几次，别让资源溢出

### 第四步：资源规划（新手最核心的部分）

**纯雨滴怎么花？**

纯雨滴是付费货币，获取有限，一定要省着花。

- 零氪/微氪玩家：纯雨滴只用来抽卡。不要买体力，不要买商店里的材料
- 月卡玩家：月卡给的多一点，但依然建议优先抽卡
- 氪金玩家：随意，但性价比最高的还是抽卡

**利齿子儿和微尘怎么刷？**

这两个是基础养成货币，角色升级和洞悉都要用，永远不够。

- 利齿子儿：荒原产出是主要稳定来源，资源本也可以刷，但体力有限
- 微尘：同样荒原产出，资源本也可以刷
- 建议：不要刻意刷这两个，靠荒原产出和活动奖励就够了。实在缺的时候再去资源本补

**体力怎么分配最划算？**

新手期体力分配优先级：

1. 主线关卡（推图解锁功能，最优先）
2. 活动关卡（限时活动，性价比高，有活动币和材料）
3. 洞悉材料（角色突破需要，根据当前需求刷）
4. 共鸣材料（共鸣等级提升很大，中期开始刷）
5. 经验材料（角色升级，缺的时候刷）
6. 利齿子儿/微尘（缺的时候刷，不要刻意刷）
7. 心相材料（前期不着急，主线推完再刷）

**哪些材料先刷、哪些以后刷？**

先刷的：
- 洞悉材料（角色突破，提升最大）
- 经验材料（等级不到不能洞悉）
- 活动材料（限时，过期没了）

以后刷的：
- 心相材料（前期用系统送的就行，不用专门刷）
- 狂想材料（50级以后的事，前期不用管）
- 高阶共鸣材料（共鸣10以后再刷）

### 第五步：进阶方向（什么时候该做什么）

**什么时候开始刷心相？**

当你有了第一个洞悉III的角色之后。心相是装备系统，提供属性加成和特殊效果。前期系统会送一些心相，够用。等你开始打深眠域了，再专门刷心相材料和升级心相。

新手期推荐心相：
- 主C：掌声如雷鸣（暴击）、夜色亵渎者（异常状态增伤）
- 治疗：好奇心宝贝（减益回血）、在仙境之外（治疗率提升）
- 辅助：可度量之心（激情增伤）

**什么时候开始打人工梦游？**

通关主线解锁后就可以打。浅眠域新手期就能打，难度不高。深眠域建议等你有一个洞悉III的主C和洞悉II的辅助治疗之后再尝试。

**什么时候考虑配体系队？**

当你至少有一个体系的核心角色时。比如你抽到了伊索尔德，就可以开始围绕她组燃烧队。如果核心角色都没有，就不要强行凑体系，用通用克制队（根据敌人灵感选克制角色）就行。

**什么时候开始练第二队？**

当你第一队已经成型（主C洞悉III、共鸣10+、心相50级+），并且开始打深眠域需要两队的时。在此之前，集中资源养一队。

## 常见问题解答

**Q：我抽到了XX，厉害吗？**

新玩家关心的几个常见6星评价：

- 37：版本常青树，强，抽到直接练
- 维拉：第一治疗，抽到直接练
- 伊索尔德：燃烧体系核心，抽到直接练，没有她玩不了燃烧队
- 诺谛卡：薪血体系天花板，高爆发，但需要操作
- 伊戈尔：仪式体系核心，12激情上限，版本答案级强度
- 程和光：追击体系核心，追击体系天花板
- 牙仙：开服至今依然强势，治疗+净化，泛用性强
- 环状水星：百搭辅助，放进任何队伍都好用
- 可燃点：燃烧体系爆发输出，但没有伊索尔德的话强度打折扣
- 红弩箭：开服战神，现在强度一般，新手期不建议优先练
- 未锈铠：开服角色，强度落后版本，不要优先练

**Q：这个角色怎么配队？**

看角色定位：
- 输出角色：配一个治疗+一个辅助+一个灵活位
- 治疗角色：配一个主C+一个辅助+一个灵活位
- 辅助角色：配一个主C+一个治疗+一个灵活位

通用公式：1输出 + 1治疗 + 1辅助 + 灵活位（根据关卡机制调整）

灵感克制也很重要，尽量让队伍覆盖3种以上灵感，避免被单一灵感克制。

**Q：体力用完了怎么办？**

- 等自然恢复（每6分钟恢复1点）
- 使用细胞活性道具（活动、通行证给）
- 升级可以恢复体力
- 零氪玩家不建议用纯雨滴买体力
- 每天上线两次清体力，避免溢出

**Q：打不过主线怎么办？**

- 先提升角色等级和洞悉等级
- 检查共鸣等级，共鸣比等级更重要
- 看看是不是灵感被克制了，换克制角色
- 借好友助战（如果有这个功能）
- 实在打不过就刷资源本提升练度，过几天再来

**Q：要不要抽这个卡池？**

- 新手池（第一滴雨）：30次内必出6星，必抽，性价比最高
- 限定角色：如果强度高且适合你的体系，值得攒保底抽
- 常驻角色：除非是你正在组的体系核心，否则建议攒着等限定
- 通用原则：新手期建议攒够保底再抽，不要分散抽。零氪玩家只抽限定和强力角色

**Q：心相是什么？怎么获得？**

心相是角色的装备系统，提供属性加成和特殊战斗效果。每个角色可以装备1个心相。心相可以升级、突破、增幅。

获得方式：
- 通行征集（抽卡）获得
- 银行使用迷途之声兑换
- 活动商店兑换
- 限定心相从特定活动获取

新手期先用系统送的，等有了洞悉III的角色再专门刷心相。

**Q：狂想是什么？怎么开启？**

狂想是特定角色的强化系统，解锁新技能或强化现有技能。需要通关主线5TH-20解锁雨中悬想，然后在雨中悬想中获取狂想材料（浮想之芽、灵机之种等）。

新手期不用管狂想，这是中后期内容。50级以后再考虑。

**Q：塑造是什么？需要抽满吗？**

塑造是重复获得同一角色后，提升其技能数值的系统。最高5塑。

- 0塑（本体）已经能体验完整机制
- 1-2塑提升数值，不是必须
- 3-5塑大幅提升，但只有氪金玩家才需要考虑
- 零氪/微氪玩家：0塑就够了，不要为了塑造去抽同一个角色

## 角色培养优先级

### 优先培养的6星角色

**绝对优先（抽到必练）**

- 37（星/精神/追击/灵光）：版本常青树，多个版本依然强势，灵光追击机制，泛用性强
- 维拉（木/精神/治疗/升阶/净化）：版本第一治疗，暴击暴伤拐，抽到直接替换苏芙比
- 伊索尔德（灵/现实/燃烧）：燃烧体系绝对核心，狂想后更强，抽到她就有了一个体系
- 环状水星（灵/精神/辅助/升阶）：百搭辅助，升阶机制，放进任何队伍都好用

**推荐优先（抽到可以练）**

- 伊戈尔（兽/现实/仪式/子弹）：仪式体系核心，12激情上限，版本答案级强度，但需要体系配合
- 诺谛卡（灵/现实/薪血）：薪血体系天花板，高爆发，但需要操作和理解
- 北方哨歌（星/精神/额外行动/灵光）：暴击爆发型，狂想后更强，但需要一定练度
- 可燃点（兽/现实/燃烧）：燃烧体系爆发输出，配合伊索尔德很强，但单独用强度一般
- 程和光（星/现实/追击/额外行动）：追击体系核心，但需要体系配合
- 牙仙（星/精神/治疗/净化）：开服至今依然强势，治疗+净化，泛用性强
- 乌尔里希（智/现实/电能）：电能体系核心，但体系较封闭，需要一整套角色
- 虚构集（岩/现实/仪式/辅助）：让队友放仪式，强但需要体系配合
- 玛尔纱（兽/现实/护盾/余辉/辅助/净化）：余辉体系生存位，护盾+减伤+净化，泛用性强
- 拉莫纳（木/精神/中毒/改写）：中毒体系核心，但需要体系配合
- 洛伦兹蝴蝶（智/精神/辅助/余辉/输出/改写）：余辉体系核心，机制独特
- 告死鸟（智/精神/电能/吟诵/术阵）：电能体系输出，但需要体系配合

**可以练但不是优先（资源富裕再考虑）**

- 露西（智/现实/电能）：老牌强力角色，但电能体系已经有更优选择
- 曲娘（岩/现实/额外行动/吟诵）：开服老将依然能打，但不是版本最优
- 梁月（星/现实/额外行动/免疫）：单体输出优秀，但泛用性不如37
- 天使娜娜（兽/精神/输出/控制/吟诵）：契约+魅惑控制，但机制复杂，新手不推荐
- 葛天（兽/现实/辅助/吟诵/术阵）：术阵增伤辅助，但需要狂想后才强
- 槲寄生（木/控制/辅助）：石化控制，特定关卡有奇效，但泛用性一般

### 值得培养的5星角色

- 气球派对（星/治疗）：四星战神，治疗量可观，没有6星治疗时首选，值得投入资源
- 十四行诗（岩/现实/辅助/输出）：御三家，新手期绝对核心，可以练到洞悉II，后期退居二线
- 苏芙比（木/现实/治疗）：御三家，前期治疗，可以练到洞悉II，后期如果有更好的治疗可以替换
- 星锑（星/精神/输出）：御三家，前期副C，可以练到洞悉II，后期如果有更好的6星输出可以替换
- 五色月（木/控制）：石化控制，特定关卡有奇效，资源富裕可以练
- 坦南特（兽/护盾/辅助）：护盾辅助，新手期可用
- 帕米埃（兽/治疗）：治疗型角色，没有6星治疗时的备选

### 暂时不要投入资源的角色

- 所有3星及以下角色：完全不要碰
- 红弩箭（星/现实/追击）：开服战神，现在强度一般，新手期资源紧张不要优先练
- 未锈铠（岩/现实）：开服角色，强度落后版本，不要优先练
- 温妮弗雷德（岩/现实）：开服角色，强度一般，不要优先练
- 皮克勒斯（岩/精神/驱散）：驱散功能性角色，但输出一般，不推荐新手优先练
- 星之眼（星/控制）：控制型角色，但输出低，不推荐新手优先练
- 大部分没有体系配合的散件角色：除非你正好缺一个定位，否则不要分散资源

## 常见误区

**1. 不要平均培养（资源分散）**

新手最常犯的错误就是把资源平均分给所有角色，结果每个角色都半吊子，哪个都打不出伤害。正确做法是集中资源培养一个主C，主C洞悉III了再养下一个。

**2. 不要花纯雨滴买体力（除非氪金玩家）**

纯雨滴是抽卡资源，买体力性价比极低。零氪玩家一天只有有限的纯雨滴来源，花在体力上就等于少抽卡。体力用完了就等恢复，或者做别的。

**3. 不要跳过剧情（会影响对游戏的理解）**

1999的剧情是游戏最大的亮点之一，文学性很强，有很多文化梗和哲学讨论。跳过剧情不仅会错过精彩的故事，也会影响对角色和世界观的理解。至少看一遍，二周目再跳过。

**4. 不要盲目追求体系队（先练通用队）**

新手期角色池浅，强行凑体系队往往练度不够，还不如用通用克制队。正确做法是：先用御三家+抽到的强力角色组通用队，等有了体系核心角色（如伊索尔德、37、伊戈尔）再考虑转型。

**5. 不要忽视低星角色（有些低星很强）**

虽然大部分低星角色不值得练，但少数几个低星战神值得注意：

- 气球派对（四星）：治疗量不输6星，没有6星治疗时的最佳选择
- 十四行诗（五星）：御三家，新手期绝对核心，值得练到洞悉II
- 莉拉妮（四星）：增伤辅助，新手期可用
- 五色月（五星）：石化控制，特定关卡有奇效

**6. 不要忘记利用荒原**

荒原产出利齿子儿和微尘，是稳定的养成资源来源。记得每天上线收菜，定时升级建筑提高产出。荒原的素材合成功能也很重要，可以把低级材料合成为高级材料。

**7. 不要忽视共鸣等级**

很多新手只关注角色等级和洞悉，忽略了共鸣等级。实际上共鸣等级带来的属性提升非常大，甚至比角色等级更重要。建议主C共鸣10以上，治疗和辅助共鸣5以上。

**8. 不要以为抽到6星就无敌了**

6星角色需要练度支撑，0级0洞悉的6星不如一个洞悉II的4星。抽到强力6星只是第一步，练起来才是关键。

## 日常/周常清单

### 每日必做清单

1. 登录领每日奖励
2. 荒原收菜（利齿子儿、微尘）
3. 魔精公司收菜+喂食
4. 清体力（优先主线/活动，其次资源本）
5. 完成活跃度任务
6. 检查角色信任度进度

### 每周必做清单

1. 人工梦游浅眠域（重置后打完）
2. 鬃毛邮报（至少打一次，拿保底分）
3. 雨中悬想寻思（4次扫荡，用掉）
4. 活动关卡（如果有，清完活动币）
5. 银行兑换（迷途之声兑换心相或材料）
6. 检查荒原建设，升级建筑

### 优先级总结

推主线 > 刷活动 > 刷洞悉材料 > 刷共鸣材料 > 刷心相材料 > 刷经验材料

## 新手期目标路线图

### 1-20级（纯新手期）
- 目标：推主线到1ST-16
- 阵容：御三家（十四行诗+星锑+苏芙比）+ 任意抽到的角色
- 练度：洞悉I，等级拉到上限
- 不碰：深眠域、雨中悬想、鬃毛邮报

### 20-35级（开荒期）
- 目标：推主线到5TH-20，解锁所有功能
- 阵容：确定主C，围绕主C组队
- 练度：主C洞悉II，治疗洞悉I，辅助洞悉I
- 开始：打浅眠域、鬃毛邮报（低分）
- 不碰：深眠域、雨中悬想迷思海

### 35-50级（过渡期）
- 目标：第一队成型
- 阵容：主C+治疗+辅助+灵活位
- 练度：主C洞悉III+共鸣10，治疗洞悉II+共鸣5，辅助洞悉II+共鸣5
- 开始：尝试深眠域、刷心相材料
- 不碰：雨中悬想迷思海深层

### 50级+（中期）
- 目标：第二队成型，开始打深眠域
- 阵容：两队体系队或通用队
- 练度：第一队全部洞悉III+共鸣10+，第二队洞悉II+共鸣5+
- 开始：雨中悬想迷思海、狂想材料、心相增幅
- 目标：深眠域通关、鬃毛邮报SS评分

## 新版本该做什么

每个新版本（约28天一个大版本）更新后，建议按以下顺序做：

1. 推主线版本的主线关卡
2. 打活动关卡，刷活动币，换完活动商店
3. 抽当期角色（根据强度和体系需求决定）
4. 练新角色（如果抽到了）
5. 继续日常周常

版本活动商店性价比很高，活动币换养成材料比直接刷资源本划算。活动期间体力优先刷活动本。
