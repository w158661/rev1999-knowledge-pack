# 重返未来1999 数据快速查询技能

## 技能定位

本技能用于快速搜索《重返未来1999》的原始数据文件。当需要深入查询某个角色、事件、物品或设定时使用。

## 数据源

原始数据在 `data/` 目录下，共760个文件（数据根目录由 `REV1999_DATA` 环境变量指定）。

## 查询方法

### 方法1：grep全文搜索
```bash
grep -ri "关键词" $REV1999_DATA/skill_*.md
```

### 方法2：按目录搜索
```bash
# 角色
grep -ri "关键词" $REV1999_DATA/角色/ $REV1999_DATA/角色列表/

# 剧情
grep -ri "关键词" $REV1999_DATA/主线/ $REV1999_DATA/支线/

# 世界观
grep -ri "关键词" $REV1999_DATA/世界观设定/ $REV1999_DATA/小径/

# 游戏系统
grep -ri "关键词" $REV1999_DATA/鬃毛邮报/ $REV1999_DATA/心相/

# 活动
grep -ri "关键词" $REV1999_DATA/轩事/ $REV1999_DATA/活动/
```

### 方法3：查询脚本
```bash
bash scripts/query.sh "关键词" all
bash scripts/query.sh "关键词" character
bash scripts/query.sh "关键词" story
bash scripts/query.sh "关键词" world
```
