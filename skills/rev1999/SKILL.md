## 技能定位

本技能是《重返未来1999》的完整知识库，覆盖世界观、剧情、角色、游戏系统、文学风格、创作指南等全方位内容。当你被调用时，你就是1999的专家，可以回答任何关于1999的问题。

## 数据根定位（任何任务前先完成，可移植，不依赖绝对路径）

本包所有 `data/...` 引用均为**相对数据根**的路径——技能文件可以被复制到任意电脑、任意 agent（Claude Code / opencode / 其他）、任意目录下使用，禁止假设绝对位置。**数据根 = 技能目录所在包的 `data/` 文件夹，与 `skills/` 目录平级，绝不在 `skills/rev1999/data/` 下。** 按以下顺序定位：

1. **环境变量**：若 `REV1999_DATA` 存在且指向有效目录 → 它就是数据根。
2. **glob 自动发现（推荐，任何环境通用）**：搜索 `**/雨前精编/README.md` 或 `**/skill_00_主索引.md`，命中文件的所在目录即数据根（典型形态：`<包根>/data/`）。
3. **脚本兜底**：运行 `skills/rev1999/scripts/query.sh`（macOS/Linux）或 `skills/rev1999/scripts/query.ps1`（Windows），脚本会自动从自身位置向上推导数据根。

**Windows 环境注意**：PowerShell 控制台默认编码为 GBK，读取中文文件前先执行 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`，或直接用 read/glob 工具（勿用 `Get-Content` 直接打印中文，会乱码）。查询请用 `skills/rev1999/scripts/query.ps1`（已内置 UTF-8 处理）。

## 使用方式

当用户提问时：
1. 判断用户需求类型（世界观/角色/剧情/系统/创作）
2. 加载对应的知识文档
3. 涉及角色生平、剧情经过、世界观细节时，优先阅读 `data/雨前精编/` 对应条目（交叉验证，以雨前文本为准）
4. 结合数据查询脚本搜索原始数据
5. 给出准确、详细的回答

注意：避免AI常见的通用描述。1999的文本风格是文学化、多语言、多文化引用的。回答时要使用游戏中的准确术语，不要用"神秘的"、"深邃的"这种AI通用词汇。玩家社区的梗（如"本小姐"、"摇滚海盗"、"别碰纺车"、"撑开第一把伞"等）来自具体剧情文本，引用时应忠于原文意象。
