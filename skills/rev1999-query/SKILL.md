# 重返未来1999 数据快速查询技能

## 技能定位

本技能用于快速搜索《重返未来1999》的原始数据文件。当需要深入查询某个角色、事件、物品或设定时使用。

## 数据源

原始数据在 `data/` 目录下，共6255个文件（另含3份实测报告，全量6235；数据根目录由 `REV1999_DATA` 环境变量指定）。

## 查询方法

### 方法1：grep全文搜索
```bash
grep -ri "关键词" $REV1999_DATA/skill_*.md
```

### 方法1b：扩充卷全文搜索（深度数据）
```bash
grep -ri "关键词" $REV1999_DATA/扩充/
```

### 方法1c：战斗关卡搜索
```bash
grep -ri "关键词" $REV1999_DATA/战斗关卡/
# 或 query.ps1/query.sh 的 stage 类型
```

> **检索优先级建议（重要）**：
> 1. **日常查询用 grep / query.ps1 / query.sh**——快、无需构建、结果可读。
> 2. **深度语义检索用 search_index.py**——`python scripts/search_index.py build --datadir <数据根>` 构建后 `search ...` 可用；注意全库（6000+文件）构建产物约数百MB、加载较慢（数十秒级），适合离线构建后复用，不适合每次会话重建；查询时若超时，改用 grep 兜底。
> 3. **快速角色定位**：先查 roleplay 技能书签表（20高频角色四跳直达），再查 `扩充/00_扩充卷速查.md` 选卷。

### 方法2：按目录搜索
```bash
# 角色
grep -ri "关键词" $REV1999_DATA/角色/ $REV1999_DATA/角色列表/

# 剧情
grep -ri "关键词" $REV1999_DATA/主线/ $REV1999_DATA/支线/

# 世界观
grep -ri "关键词" $REV1999_DATA/世界观设定/ $REV1999_DATA/小径/

# 游戏系统
grep -ri "关键词" $REV1999_DATA/鬃毛邮报/ $REV1999_DATA/心相/

# 活动
grep -ri "关键词" $REV1999_DATA/轩事/ $REV1999_DATA/活动/
```

### 方法3：查询脚本
```bash
bash scripts/query.sh "关键词" all
bash scripts/query.sh "关键词" character
bash scripts/query.sh "关键词" story
bash scripts/query.sh "关键词" world
```
