## 核心机制

### 灵感克制链
兽→木→星→岩→灵→智→兽
被克制时伤害降低30%

### 创伤类型
- 【现实创伤】受敌人现实防御影响
- 【精神创伤】受敌人精神防御影响

### 角色定位
- 输出：主C，核心伤害来源
- 治疗：回血，保障生存
- 辅助：增伤、减伤、控制
- 护盾：提供护盾，吸收伤害
- 控制：缴械、封印、眩晕等

## 配队基本原则

### 1. 灵感平衡
确保队伍有足够的灵感覆盖，避免被单一灵感克制

### 2. 角色定位互补
标准队伍构成：1输出 + 1治疗/护盾 + 1辅助/控制 + 灵活位

### 3. 体系搭配
根据角色机制组建体系队，发挥1+1>2的效果

### 4. 心相搭配
每个角色应选择与其机制匹配的心相，关注加成效果

### 5. 调律选择
根据队伍打法选择合适的调律方案

## 详细配队体系

### 燃烧体系

【体系概述】
围绕燃烧层数进行输出的体系，核心机制是叠层→引爆循环。燃烧层数越高，伤害越爆炸。伊索尔德是叠层发动机，可燃点是爆发收割手。

【核心角色】
- 伊索尔德（灵/现实/燃烧核心）：热度进阶（序曲→幕间曲→终曲），敌方燃烧层数达6时自动释放间奏曲追击，仪式提供激昂和大量燃烧。狂想追加余辉体系和光晕状态。燃烧体系绝对核心，没有她玩不了燃烧。
- 可燃点（兽/现实/燃烧输出）：通过预燃和振奋状态提升暴击率和暴击创伤，暴击时额外叠加燃烧层数，仪式对高燃烧层数目标造成巨额暴击伤害。狂想追加余辉体系。

【辅助角色】
- J（兽/现实/生存/燃烧）：受击对敌方施加燃烧，提供反制反击，承担生存位，燃烧叠层工具人。
- 和平乌鲁：可燃点绑定伙伴，提供火焰增益，燃烧辅助。
- 洛佩拉（兽/现实/燃烧/辅助）：燃烧子弹分发，吟诵预备开火，坩埚军火库术阵提升暴击率。

【替代角色】
- 无伊索尔德时可以用任意燃烧角色勉强替代，但强度差很多
- 生存位可用任意治疗替代

【推荐心相】
- 伊索尔德：沉默与向往（额外行动增伤）/ 夜色亵渎者（异常状态增伤）
- 可燃点：掌声如雷鸣（暴击）/ 此刻无新事（兽灵感穿透）
- J：女佣看见了（术阵附加效果）

【调律推荐】
- 未尽的调律（快速启动，伊索尔德需要尽快进入终曲阶段）
- 最初的刻度（均衡通用）

【打法思路】
1. 开局优先让伊索尔德叠热度，快速进入终曲阶段
2. 利用J或洛佩拉叠加燃烧层数
3. 可燃点找机会用仪式打出爆发伤害
4. 注意燃烧层数管理，6层以上触发伊索尔德追击
5. 对方群体时优势明显，单体BOSS时注意点燃多个目标

### 电能体系

【体系概述】
围绕电能层数进行循环输出的体系，核心机制是电能积累→消耗→强化的循环。循环越久伤害越高，属于持续输出型体系。

【核心角色】
- 乌尔里希（智/现实/电能核心）：电能体系核心，破译组长级的工作效率，利用电能升级咒语和术阵，持续输出能力极强。磁流体机器人意识唤醒者。
- 卡戎（灵/精神/电能辅助）：电能体系辅助核心，提供电能循环增益，与乌尔里希配合形成完整循环。

【辅助角色】
- 哑谜（智/现实/电能/护盾）：电能体系护盾位，提供额外电能，护盾辅助。
- 告死鸟（智/精神/电能/输出/吟诵）：电能体系输出型角色，吟诵削弱敌人精神防御，电弧光和断裂点层数系统，仪式触发吟诵攻击。

【替代角色】
- 露西（智/现实/电能/输出）：电能体系输出位。3.2 狂想"阶梯尽头，应是黎明"后强度显著提升：敌方退场永久强化+额外行动，仪式后克制所有灵感，泛用性极高。可作电能体系副C，也可脱离电能体系当通用队主C（配 维拉/牙仙/环状水星+灵活位）
- 灰调蓝（兽/精神/电能/辅助/术阵）：电能体系辅助位，术阵提供增益

【推荐心相】
- 乌尔里希：跳房子游戏（击败增伤）/ 夜色亵渎者
- 卡戎：可度量之心（激情增伤）
- 告死鸟：秒针栖息地（吟诵穿透）
- 露西（电能体系/通用主C）：记录重构（术阵收益）/ 夜色亵渎者；狂想后优先选择强化"额外行动"收益的心相

【调律推荐】
- 最初的刻度（均衡型，稳定循环）
- 伟大乐队（操作型，需要频繁调整咒语）
- 露西：狂想后可选 未尽的调律（快速启动额外行动节奏）

【打法思路】
1. 乌尔里希和卡戎互相配合积累电能
2. 利用电能升级咒语，打出高阶伤害
3. 告死鸟吟诵持续削弱敌人
4. 哑谜提供护盾和额外电能
5. 属于持续输出型，不追求秒杀，注重循环

### 术具体系

【体系概述】
围绕同调值和交感能量运作的体系，术具角色通过特殊咒语循环获得能量，释放强力的术具效果。节奏独特，上手需要一定练习。

【核心角色】
- 双生舞伶（岩&星/双灵感/术具核心）：拥有同调值系统替代激情系统，双灵感属性可同时触发两种克制效果。术具体系绝对核心。
- 回声谣（岩/现实/治疗/术具/辅助）：术具体系治疗型角色，赋予队友告慰之歌和余念机制承担伤害，提供混沌交感能量，无需消耗能量即可为全队提供创伤加成。

【辅助角色】
- 珐琅眼：术具辅助角色，提供额外术具增益

【替代角色】
- 术具体系较封闭，缺核心角色时建议用其他体系

【推荐心相】
- 双生舞伶：沉默与向往 / 夜色亵渎者
- 回声谣：好奇心宝贝（减益回血）/ 在仙境之外

【调律推荐】
- 无调性序列（交感型，与术具体系完美匹配）
- 未尽的调律（资源型）

【打法思路】
1. 双生舞伶积累同调值，进入术具状态
2. 回声谣提供生存保障和混沌交感能量
3. 利用术具特殊咒语打出高额伤害
4. 注意同调值的维持，不要断档
5. 无调性序列调律与术具体系机制高度契合

### 灵光体系

【体系概述】
围绕灵光机制运作的体系，通过积攒和消耗灵光触发额外行动和追击。操作上限高，伤害上限也高，属于技巧型体系。

【核心角色】
- 37（星/精神/输出/追击/灵光核心）：灵光核心输出，依靠自身释放咒语或队友额外行动积攒灵光，达到5点消耗释放追击补充算式对全体造成伤害，所有咒语附加的本源创伤可暴击。
- 北方哨歌（星/精神/输出/额外行动/灵光）：暴击爆发型角色，己方暴击或赋予明昧时获得尺度层数，拥有筹备咒语机制可持有较多咒语，仪式不消耗行动点实现高频次爆发，溢出暴击率可转为暴击创伤。狂想追加强化。

【辅助角色】
- 维拉（木/精神/治疗/升阶/辅助/净化）：提供暴击暴伤加成，精神创伤角色额外加成，升阶咒语，驱散净化全队，回激情灵光。
- 纸信圈儿（星/现实/辅助/额外行动/吟诵/灵光）：风速力场系统，连续行动提供额外行动点，吟诵转化全队咒语为群体攻击。

【替代角色】
- 6（智/灵光/辅助）：灵光辅助角色，可替代部分功能
- 马库斯（木/精神/输出/升阶/灵光）：灵光输出型角色，但需要高练度

【推荐心相】
- 37：沉默与向往（额外行动增伤，完美适配）
- 北方哨歌：掌声如雷鸣（暴击）
- 维拉：在仙境之外 / 好奇心宝贝

【调律推荐】
- 未尽的调律（资源型，快速获得咒语和激情）
- 最初的刻度（均衡型）

【打法思路】
1. 37通过自己和队友的额外行动快速积攒灵光
2. 北方哨歌利用暴击和尺度层数打出爆发
3. 维拉提供暴击暴伤和升阶，精神创伤角色额外受益
4. 注意灵光条管理，5点灵光立刻消耗打追击
5. 额外行动角色越多，灵光积攒越快
6. 纸信圈儿提供额外行动点进一步加速循环

- 星锑（星/精神/输出/启示）：启示输出型角色，配合远旅打出高额即兴咒语伤害。
- 芭卡洛儿（星/精神/输出/启示/辅助）：启示体系输出+辅助，啪唧匣子提供多种乐器效果。

- 阿莱夫（智/精神/辅助/启示/吟诵/灵光）：启示辅助角色，提供吟诵和灵光增益。

【替代角色】

【推荐心相】
- 远旅：沉默与向往 / 夜色亵渎者
- 星锑：掌声如雷鸣（暴击）
- 芭卡洛儿：在仙境之外

【调律推荐】

【辅助角色】

【替代角色】

- 可燃点（狂想后追加余辉体系）：可作为余辉体系插件

【推荐心相】

- 洛伦兹蝴蝶：可度量之心 / 夜色亵渎者

【推荐心相】

【辅助角色】

2. 利用额外行动角色增加行动次数
3. 10层羽刃后仪式不耗行动点，必暴击
4. 37利用队友额外行动积攒灵光打追击
5. 一回合内打出多次攻击，伤害频率极高

### 中毒体系

【体系概述】
围绕中毒层数进行输出的体系，持续伤害积累型。中毒叠层后引爆造成巨额伤害，节奏偏慢但伤害上限高。

【核心角色】
- 拉莫纳（木/精神/输出/中毒/改写）：中毒体系核心，改写咒语表面使己方使用后触发追击，除灵剂使中毒额外结算，仪式将多个中毒转化为灵魂溶剂造成高额本源创伤，持续越久伤害越高。
- 笃笃骨（木/精神/输出/中毒/吟诵）：中毒体系输出，吟诵强化中毒效果，独腿女巫的愤怒。

【辅助角色】
- 洁西卡（木/中毒/输出）：中毒体系输出，可提供额外中毒叠层。
- 蓝手帕/数羊羔（灵/精神/输出/中毒/辅助/术阵）：中毒体系辅助，术阵提供中毒增益。

【替代角色】
- 任意治疗角色
- 苏芙比（木/现实/治疗）：中毒体系治疗，可配合中毒角色

【推荐心相】
- 拉莫纳：夜色亵渎者（异常状态增伤，完美适配）
- 笃笃骨：掌声如雷鸣 / 夜色亵渎者

【调律推荐】
- 未尽的调律（资源型，快速叠毒）
- 最初的刻度（均衡型）

【打法思路】
1. 拉莫纳和笃笃骨叠加中毒层数
2. 利用改写和除灵剂加速中毒结算
3. 拉莫纳仪式将所有中毒转化为灵魂溶剂打爆发
4. 中毒持续越久，灵魂溶剂伤害越高
5. 属于持续伤害体系，面对高血量敌人优势明显

### 仪式体系

【体系概述】
围绕至终仪式进行输出的体系，核心机制是快速积攒激情、频繁释放仪式。爆发节奏可控，伤害集中。

【核心角色】
- 伊戈尔（兽/现实/输出/额外行动/仪式/子弹）：激情上限12，消耗8点自动释放仪式，给敌方附加弹壳碎片强化仪式伤害，从军械库6种子弹中随机获得强化自身。与洛佩拉或莫莉德尔组队有特殊协同强化。
- 虚构集（岩/现实/输出/仪式/辅助）：额外激情上限，仪式可额外消耗激情造成更高伤害，特殊咒语虚构故事集让友方直接释放仪式，友方释放仪式时为虚构集回复激情并增加仪式伤害。狂想追加强化。

【辅助角色】
- 莫莉德尔（兽/现实/辅助/仪式/输出/反击）：使用咒语增加己方行动点，己方消耗激情时获得战备层数，在主见状态下使用反制咒语可直接释放仪式反击。
- 鬃毛沙砾（兽/现实/输出/仪式/辅助）：仪式体系辅助输出，提供仪式相关增益。

【替代角色】
- 任意激情回复型角色

【推荐心相】
- 伊戈尔：可度量之心（激情增伤）/ 跳房子游戏
- 虚构集：可度量之心 / 沉默与向往

【调律推荐】
- 未尽的调律（资源型，快速获得激情）
- 最初的刻度（均衡型，稳定回激情）

【打法思路】
1. 伊戈尔和虚构集快速积攒激情
2. 伊戈尔激情上限12，消耗8点自动释放仪式
3. 虚构集可让队友直接释放仪式
4. 莫莉德尔提供额外行动点和战备增益
5. 仪式体系爆发集中，适合需要快速击杀特定目标的场景

### 通用队（体系外泛用组合）

【体系概述】
不依赖特定体系机制，而是利用角色本身的强势机制和灵感克制进行配队。适合角色池不深或需要应对特定敌人的情况。

【核心思路】
- 主C（根据敌人弱点选择克制灵感）
- 辅助（增伤/减防/激情回复）
- 治疗/护盾
- 灵活位（根据关卡机制选择）

【泛用强力角色推荐】
- 输出：37、北方哨歌、伊戈尔、可燃点、诺谛卡、程和光、梁月
- 治疗：维拉、牙仙、气球派对、兔毛手袋、回声谣、苏芙比
- 辅助：环状水星、虚构集、纸信圈儿、洛伦兹蝴蝶、葛天、十四行诗
- 护盾：玛尔纱、爱兹拉、新巴别塔、库珀花环

【推荐心相】
- 根据角色定位选择对应心相

【调律推荐】
- 最初的刻度（均衡型，适用最广）

【打法思路】
1. 根据敌人弱点选择克制灵感的主C
2. 配一个保命位（治疗或护盾）
3. 配一个增伤位（辅助）
4. 灵活位根据关卡机制调整
5. 没有固定套路，见招拆招

## 游戏模式攻略

### 人工梦游

【浅眠域】
- 难度：低，新手友好
- 推荐阵容：1输出+1治疗+1辅助+灵活位
- 十四行诗+星锑+苏芙比+任意输出，纯御三家就能过
- 自动回复，不需要太在意策略
- 目标是积累星数领奖励

【深眠域】
- 难度：中等，需要练度和配队策略
- 建议准备2队，至少6个练度OK的角色
- 推荐阵容：
  - 队伍1：燃烧队（伊索尔德+可燃点+J+治疗）
  - 队伍2：通用队（克制灵感主C+辅助+治疗+灵活位）
- 注意每期的梦境增益选择，选对增益事半功倍
- 根据敌人灵感弱点调整队伍
- 需要一定的共鸣等级（建议10+）

【醒梦域】
- 难度：高，需要完整练度和深度理解
- 建议准备3队，至少9个高练度角色
- 推荐阵容：
  - 队伍1：灵光追击队（37+北方哨歌+维拉+纸信圈儿）
  - 队伍2：燃烧队（伊索尔德+可燃点+J+玛尔纱）
  - 队伍3：仪式队（伊戈尔+虚构集+莫莉德尔+治疗）
- 注意认证评级（C/B/A级），评级越高奖励越好
- 共鸣等级建议15+
- 洞悉III是基本门槛
- 心相增幅等级尽量高

【通用技巧】
- 每期先看梦境增益，围绕增益配队
- 利用克制关系，即使体系不完整也能打出高伤害
- 治疗角色练度很重要，站得住才有输出
- 共鸣等级比角色等级更重要，优先拉共鸣

### 鬃毛邮报

【BOSS打法要点总览】
- 注意隐匿度机制，3.2版本后核心系统
- 削减隐匿度至0进入目击回合，BOSS不再行动
- 控制回合数争取高分

【通用打法】
- 优先削减隐匿度，利用特殊要求快速降到0
- 目击回合全力输出，把所有爆发都留到目击回合
- 注意BOSS的伤害类型，选择对应防御
- 注意BOSS的灵感克制，选择克制角色

【各BOSS类型对策】

群体伤害型BOSS：
- 推荐：燃烧队、灵光队
- 利用群体攻击快速削减隐匿度
- 治疗位必备，群体伤害压力大
- 注意站位，避免被一波带走

单体伤害型BOSS：
- 推荐：仪式队、追击队
- 单体爆发快速削减隐匿度
- 护盾位比治疗位更有效
- 注意BOSS的锁定目标机制

爆发伤害型BOSS：
- 推荐：玛尔纱护盾队
- 高爆发需要护盾吸收
- 注意BOSS的爆发前兆，提前开盾
- 玛尔纱的自动盾和减伤很有用

额外行动型BOSS：
- 推荐：控制队
- 控制BOSS的行动频率
- 槲寄生的石化有用
- 天使娜娜的魅惑也可用

治疗型BOSS：
- 推荐：高爆发队
- 需要爆发压制，不让BOSS回血
- 仪式队和薪血队适合
- 注意驱散BOSS的增益

【尖峰聚焦模式注意事项】
- 特殊机制模式，难度更高
- 注意每期的特殊规则
- 可能需要特定角色对策
- 建议先看攻略了解机制再打

【评分技巧】
- 隐匿度削减越快，分数越高
- 目击回合输出越高，分数越高
- 注意保留爆发技能到目击回合
- 提高全队练度是根本
- 合理利用调律系统

### 新手常见问题

【Q：抽到多个6星，先练哪个？】
A：先看体系，优先培养能组成完整体系的角色。如果抽到伊索尔德，优先练燃烧体系；如果抽到37，优先练灵光体系。如果抽到的角色不成体系，优先练泛用性强的角色（37、维拉、环状水星）。

【Q：没有6星治疗怎么办？】
A：气球派对（5星）是很好的替代，治疗量不输大部分6星。苏芙比（御三家）也能用。不要因为没有6星治疗就卡关。

【Q：要不要练低星角色？】
A：四星以下不要练。五星中气球派对值得练（属最强治疗之一）。其他四星除非有特殊用途（如对策卡），否则不要浪费资源。

【Q：心相怎么选？】
A：主C优先通用心相（掌声如雷鸣、夜色亵亵者），辅助优先功能性心相（好奇心宝贝、可度量之心），治疗优先治疗心相（在仙境之外、好奇心宝贝）。限定心相如果适合角色，优先考虑。

【Q：共鸣怎么分配？】
A：主C优先拉到15，治疗拉到10，辅助拉到10。共鸣材料优先给主C，主C的共鸣等级决定伤害上限。

【Q：打不过深眠域怎么办？】
A：先提升共鸣等级，共鸣10是深眠域的基本门槛。检查心相等级，心相60级很重要。注意克制关系，即使练度不够，克制也能弥补。如果还是打不过，那就再练一周。
