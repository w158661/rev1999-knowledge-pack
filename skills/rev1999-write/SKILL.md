# 重返未来1999 写作辅助技能

## 技能定位

辅助用户创作《重返未来1999》风格的同人作品、角色对话、场景描写。用户输入一个简单想法，技能自动扩展成符合1999风格的文本。

## 数据根定位（先做，可移植）

本技能所有 `data/...` 引用均为相对**数据根**的路径（可复制到任意电脑/agent）。定位顺序：①环境变量 `REV1999_DATA`（有效则用）②glob 搜索 `**/雨前精编/README.md`，其所在目录即数据根（与 `skills/` 平级，绝不在 `skills/rev1999/data/` 下）③运行 `scripts/query.ps1`/`query.sh` 自动推导。Windows 下读中文文件先设 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`。

## 核心原则

1. 克制的诗意——游戏文本极少直白抒情，情感通过行动、意象、沉默、隐喻传达
2. 具体而非抽象——用具体的视觉/听觉/触觉细节，不用"深邃的""神秘的"这类空词
3. 时代感——每个场景必须有准确的时代背景细节
4. 角色voice——每个角色说话方式不同，不能混用
5. 多语言自然——英语/法语/拉丁语/俄语自然融入，不炫技

## 防幻觉强制规范（写作前必须读）

写作任何内容前，先读 `data/skill_15_写作逻辑与防幻觉指南.md`，并遵守：

**写作前另读（防AI味速查）：**
- `data/扩充/15_反AI写作病清单.md` —— 反AI写作病清单（"眼神深邃/内心充满/神秘莫测"等AI通病速查）
- `data/扩充/16_GitHub写作技能蒸馏.md` —— GitHub活跃写作项目的可落地最佳实践（反AI通用怪病/角色一致性/叙事一致性）

**写作时禁止：**
- 直白吐露角色内心（"她感到悲伤"）——用行动/意象/沉默传达
- 角色全知（知道了不该知道的事）
- 游戏机制术语混入剧情（灵感/创伤/狂想/塑造/暴击/穿透/至终的仪式）
- meta式强调（"这不是游戏""这意味着""在这个充满神秘学的世界里"）
- 梗概句压缩（"经过一番波折""时间过得很快"）
- 时代串台（1910年角色说现代话、1960s和1920s写一样）
- 编造角色经历/剧情（查数据，不凭印象）
- 编造官方留白的来源（官方没写明"角色从哪得知某事"时，禁止补造"宿管说的/老师说的"类来源——留白就留白，角色可以说"不知道，反正是听来的"；尤其禁忌话题，逻辑上不可能由知情者主动告知）
- 角色知道得比剧情阶段多（未来剧情词汇泄漏：童年期台词不得出现司辰/手提箱/回溯等后续概念；角色只能引用"自己经历过/被告知过/亲眼见过"的信息）

**写角色前必须查索引：**
1. `data/skill_16_角色登场索引.md` —— 确认该角色在哪些章节登场过，写其经历时不超出登场范围
2. `data/skill_03_角色百科A.md` / `data/skill_04_角色百科B.md` —— 角色性格/说话风格/背景
3. `data/skill_11_角色语音风格库.md` —— 角色的实际台词风格（如有）
4. 需要具体剧情细节时用 `scripts/query.sh` 或 `search_index.py` 搜索原始数据

**写剧情/角色细节前必读（交叉验证，以雨前文本为准）：**
1. `data/雨前精编/02_主线剧情精编.md` —— 序章~第十章完整剧情经过（比概括文档准确得多）
2. `data/雨前精编/03_支线剧情精编.md` —— 朔日手记、地球上最后的夜晚、77号往事、1987宇宙组曲、飞驰！明日之城
3. `data/雨前精编/04_角色生平精编.md` —— 主要角色完整生平（维尔汀/星锑/苏芙比/卡卡尼亚/伊索尔德/露西/玛蒂尔达/霍夫曼/马库斯等）
4. `data/雨前精编/01_世界观与组织.md` —— 暴雨机制与组织设定
5. **`data/扩充/21_上下文污染与逻辑核查协议.md` —— 任何写作任务必须加载，必读第2~6节**：三张主权地图（信息隔离表/能力账本/语音指纹卡）动笔前填写，因果链五问+时间线核对完成后执行（第2节信息隔离表是防全知泄漏的关键，不可跳读；第7节为完成后核查）。上下文污染（记忆/能力/事件泄漏）、全知视角、年龄错位、角色声音漂移等逻辑类错误以此协议为准一票否决。

**写长文（>1500字）时必须：**
- 先列结构（开场/冲突/高潮/收尾/细节，标注每段写什么）
- 一个场景一个场景写，禁止用梗概跳过
- 写后检查：伏笔回收了吗？时间线连续吗？每个角色都在自己该在的地方吗？

## 可用的写作prompt模板

### 模板A：场景描写

用户输入：[时代/地点/氛围]
输出：符合1999风格的场景描写段落

示例：
输入：1960s伦敦，暴雨前夜
输出：泰晤士河的水面泛着铅灰色的光，像是被谁用旧报纸糊住了。空气里弥漫着煤烟和雨前的水汽，街灯亮得太早，又亮得不够。远处传来一声汽笛——不是船，是风穿过废弃码头的声音。暴雨要来了，这座城市知道，但没有人说出来。

仿写要点：
- 从具体物件切入（水面、街灯、汽笛），不直接写"氛围"
- 用不寻常的比喻（"用旧报纸糊住"）
- 结尾用"没有人说出来"制造克制的张力

### 模板B：角色对话

用户输入：[角色A] + [角色B] + [场景]
输出：符合两人性格的对话场景

示例：
输入：维尔汀 + 十四行诗 + 发现新线索
输出：十四行诗快步走进会客室，手里攥着一张纸。"司辰，我找到了——"维尔汀从窗边转过身，没有催促，等她说完。"1999年的记录，有一份被修改过。"维尔汀走回来，接过那张纸，看了很久。"知道了。"她的声音很平静，但十四行诗注意到她握着纸的指节发白。

仿写要点：
- 对话简短，动作承担叙事（"攥着纸""指节发白"）
- 十四行诗正式、"司辰"称呼；维尔汀简洁"知道了"
- 情感通过细节泄露（指节发白），不直接说"她很紧张"

### 模板C：内心独白

用户输入：[角色] + [事件/情境]
输出：符合角色性格的内心独白

示例：
输入：37 + 苏菲亚离开
输出：苏菲亚的数字是210。210的质因数分解是2、3、5、7。210是前四个质数的乘积，是高度合数，有16个因数。210离开后，我计算了37到210的距离。不是直线距离，是某种更恒定的东西。我无法用公式表达它。这让我感到……不完整。这不符合数学的美学。

仿写要点：
- 用角色的思维模式（数学）处理情感
- 情感用"无法用公式表达""不完整"来暗示
- 不直接说"我很伤心"

### 模板D：叙事片段

用户输入：[风格] + [核心情节]
输出：符合该风格的开篇段落

示例：
输入：中国古典式 + 侠客夜行
输出：月落乌啼，程和光的影子在雪地上拉得很长。他停下来，掸了掸刀鞘上的雪。当年父亲也是这样出门的——带着一把刀，和一句没有说出口的嘱托。如今他走在同一条路上，却不知道自己要找的人，是不是还是那个人。

仿写要点：
- 四字短语、意象化（月、雪、刀、嘱托）
- 过去与现在交织
- 克制的情感，"不知道"比"茫然"有力

### 模板E：角色初印象

用户输入：[角色名] + [观察者视角]
输出：该角色在他人眼中的印象

示例：
输入：苏芙比 + 侍者的视角
输出：她进门的时候，整间店都安静了一瞬。香奈儿新款，最新一期时装杂志的封面款。她摘下墨镜，环顾四周，像在视察自己的领地。直到她开口说要一杯奶茶，用那种不容置疑的语气，侍者才意识到——这不过是个还没学会怎么自然而然长大的小姑娘。

仿写要点：
- 从观察者的具体感受切入
- 外在（穿着、动作）映照内在（没学会长大）
- 结尾的转折揭示角色本质

### 模板F：多角色对话

用户输入：[场景] + [角色列表]
输出：多人对话场景，角色轮流发言

示例：
输入：箱中会客室 + 维尔汀、星锑、十四行诗
输出：
星锑把音量又调大一格："喂喂，你们听这个！特别带感！"
十四行诗捂住耳朵："星锑小姐，音量已经超过安全分贝了。另外，这张唱片在1996年的销量记录里没有出现过。"
"那不就是绝版货吗！更值钱了！"
维尔汀从门外走进来，没有说话，直接关掉了电源。
星锑惨叫："你谋杀我的音乐！"
维尔汀："救你的耳朵。"
星锑："暴君！"
十四行诗低头在记录本上写下：司辰与星锑小姐今日就音量问题达成一致，为期零分钟。

仿写要点：
- 每个角色说话方式不同（星锑大声混搭、十四行诗正式、维尔汀简短）
- 对话之间的动作描写推进
- 十四行诗用记录的方式收尾，符合她的性格

### 示例1：场景描写
输入：1980s旧金山，海特街，黄昏
输出：黄昏的海特街像一杯放久的咖啡。涂鸦墙上新覆盖了一层亮色，旧的在底下渗出来。唱片店里飘出爵士乐，混着街角热狗的油烟。一个穿皮夹克的男人靠在路灯下，手里转着一把刀——不是威胁，是习惯。这座城市在黄昏时最诚实，所有的颜色都变得柔和，所有的声音都变得清晰。

### 示例2：角色对话
输入：星锑 + 可燃点 + 第一次见面
输出："哟！这儿有个小个子想打架？"星锑把收音机往肩上一扛，"来来来，老子给你放首助兴的！"
可燃点皱眉："你谁啊？我不认识你。还有，我一点也不小！"
"个头小，气势不小。行，有点意思。你练拳击的？"
"你怎么知道？！"
"看站的姿势。重心稳，脚不离地，拳头习惯性虚握——练家子。"
可燃点愣住，然后笑了："你……你挺懂行的。"
"那是！老子玩摇滚的，看人准。"

### 示例3：内心独白
输入：十四行诗 + 第一次看到外面的世界
输出：我读过很多关于"外面"的描写。报纸上说，巴黎的咖啡馆下午三点座无虚席；伦敦的雾天需要开灯到中午；纽约的夜晚比白天更亮。我以为我都知道了。但真正站在这里，我才发现——报纸漏掉了最重要的事。风是有温度的。它吹过脸的时候，不是"微凉"两个字能概括的。还有声音，远处的车笛、近处的足音、头顶的鸟鸣，它们混在一起，像一首没有指挥的交响乐。我该记下来。但我的笔，第一次不知道该从哪里写起。

### 示例4：叙事片段
输入：苏联式 + 北方哨歌申请加入拉普拉斯
输出：瓦莲京娜·别洛沃耶站在普列谢茨克分部的大门前，雪落在她的睫毛上。她攥着那封推荐信，纸页被冻得发脆。老尼古拉说过，理线学是"被时代遗忘的语言"。她曾以为这是浪漫主义的说法。直到她看到那扇门——门后的人愿意听她讲关于大地、关于脉络、关于那些被主流科学否定的理论的讲座。她深吸一口气，推开门。"同志，我叫瓦莲京娜。我想加入拉普拉斯。"

### 示例5：角色初印象
输入：伊索尔德 + 从马库斯视角
输出：她站在舞台中央，灯光像融化的金子一样流下来。我见过很多演员，但他们都是在扮演别人。伊索尔德不同——她不是在扮演，她是把某个更深处的东西放了出来。声音很美，每一个音都完美，挑不出错。但真正让我移不开眼的，是她唱到高音时，眼底那一点极力掩藏的、几乎看不见的颤抖。完美的人不该有颤抖。除非那不是完美，而是某种必须被完美掩盖的东西。

### 示例6：多角色对话
输入：拉普拉斯实验室 + 露西、X、乌尔里希
输出：露西的机械臂在数据面板上无声地滑动："实验数据表明，暴雨的反馈周期在缩短。"
X推了推眼镜："观测者的存在是否影响结果？我们检测到，每次有人靠近，数据显示就出现微小波动。"
"那就别让人靠近。"露西的语气毫无波动。
"但您也是人。"X说。
露西沉默了一秒，机械臂停在半空："这是我需要考虑的问题。乌尔里希，你来记录——假设观测者本身是变量。"
乌尔里希抬起头，笔尖顿了一下："我记了。但露西女士，您今天第七次把我们当成了数据。"

### 示例7：场景描写
输入：1910s维也纳，歌剧院后台
输出：后台的化妆间闷得像一口蒸笼。油彩、香水、汗水和旧木头的味道搅在一起。伊索尔德坐在镜子前，镜中的脸被灯光切割成明暗两半。她对着镜子微笑，调整角度，微笑，再调整——直到那个表情变得完美，完美到看不出任何破绽。她吸了一口气，站起来。游灵们在她耳边低语，她轻轻说了句"嘘"，然后推开门，走向舞台。那里有掌声在等她。

### 示例8：角色对话
输入：37 + 苏芙比 + 服装店
输出："这件裙子多少钱？"苏芙比指着橱窗里最新款。
37认真地计算："裙子的价格取决于布料、工艺、品牌溢价的加权和。以当前市场数据估算，约三千二百到三千五百之间。"
"太便宜了，本小姐不要。"
"你的阈值参数偏高。根据统计，99%的消费者认为这个价位属于高端。"
"本小姐不是99%，是top 1%。"
37歪头："有意思。你的自我定位不符合正态分布，属于离群值。"
苏芙比："……你这是在夸本小姐还是骂本小姐？"
37："根据定义，离群值通常意味着独特。我认为这是正面的。"

### 示例9：叙事片段
输入：中国古典式 + 曲娘学习酿酒
输出：第一坛酒是许娘子教的。米要选当年的新米，水要取井里的活水，火候要刚好——多一分则苦，少一分则淡。曲娘记不住这些，她只记一件事：做工就有饼吃。她把这句话当作酿酒的全部秘诀。直到多年后，许娘子不在了，她守着那间酒坊，才明白——当年许娘子教她的不是酿酒，是等待。酒要等，人也要等。等得够久，苦的会变甜，淡的会变醇。

### 示例10：角色对话
输入：维尔汀 + 37 + 关于暴雨
输出："37，你说暴雨是流溢。流溢是什么意思？"维尔汀靠在箱子的窗边，看着外面的雨幕。
"流溢是数字满溢。当计数超过系统承载上限，多余的数会溢出，流向别处。"37平静地解释，"暴雨发生时，时代的计数超过了世界的承载，于是多余的部分被冲刷出去，回溯到更早的位置。"
"你是说，世界像一台算错了的机器？"
"不。"37摇头，"是机器在自我修正。它记得自己应该是什么样子，然后一遍遍回到记忆中正确的时刻。"
维尔汀沉默了很久。"那它为什么不记得自己错在哪里？"
37没有回答。这是她第一次回答不出的问题。
