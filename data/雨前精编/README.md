# 雨前精编（Before the Rain 融合数据）

本目录是《重返未来1999》知识技能包与社区同人互动剧本游戏《雨前演练 · Before the Rain》融合的数据源。

## 来源

- 项目：雨前演练 · Before the Rain（作者 huoyingfirefly）
- GitHub：https://github.com/huoyingfirefly/beforerain
- Gitee：https://gitee.com/fire-flies/beforerain
- 数据提取自该项目 chroma_data/chroma.sqlite3 中的 119 条世界观 RAG 片段（约5.1万字），原出处为项目内 gitignore 的 world_lore_full.txt（世界观源文档）。

## 使用方式

- 本目录是**交叉验证与补充的权威参考**：当知识文档（skill_*.md）与《雨前》文本冲突时，以《雨前》文本为准（其剧情整理质量显著高于概括性文档）。
- 角色扮演、OC创作、同人写作、剧情问答时，优先阅读对应角色的"雨前精编"条目获取细节与质感。
- 搜索索引（search_index.py build）会通过 os.walk 自动收录本目录，query.sh 的 grep 降级模式也会命中本目录。
