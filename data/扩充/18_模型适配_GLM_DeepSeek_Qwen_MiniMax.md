## 一、DeepSeek（V3 / R1 / V3.2 / V4 系列）

### 1. 模型画像（2026 社区共识）

- 网文/同人创作圈用量最大的国产模型（性价比 + 免费入口 + 长上下文）。2026 年 V4 系列（V4-Pro、V4-Flash）陆续上线，Flash 版 2026-08 前后 API 公测，社区密集实测其写小说能力（B站 星月凌云 2026-08-04、星月小丸子 2026-08-06、银杏树下写小说 2026-08-06）。
- 社区定位高度一致：**"直接写正文不行，跑设定、拆细纲、扩剧情、润色可以"**（起点编辑切片君 B站 2025-02；后续一年被反复引用）。即它是"创作管线里的大纲/素材引擎"，不是"成稿引擎"。
- 2026-06 起出现行业级吐槽：**"过去半年所有 AI 的写作能力断崖式暴跌"**（C哥聊科技 B站 2026-06-03，11.9 万播放）。DeepSeek 新模型"文笔/描写质量"被认为不如 2025 年上半年的 V3 早期版本；部分老作者锁旧版本或坚持 V3 系（银杏树下写小说 2026-08）。
- 推理模型（R1 系/深度思考模式）的"分析腔"是最大槽点：正文前先输出大段思考分析，正文易带"论文味/总结腔"，需明确指令"不要输出思考过程、直接给正文"。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|
| 创作/文笔 | 中 | 短段落、场景扩写出色；长段连写易"AI 味"（排比、成语堆砌、情绪总结句）；2026 新模型被指文笔整体下滑（B站 2026-06）。 |
| 指令遵循 | 强 | 对结构化提示词（设定表、分条指令、禁止项清单）响应极好；同一套技能包提示词在 DeepSeek 上通常"最听话"，复杂约束能保持。 |
| 幻觉控制 | 中偏弱 | 编人名、地名、术语很顺口（同人场景下"顺着原设编新设定"）；R1 系推理会"自圆其说"，把编造讲得像设定。 |
| 长文一致性 | 中 | 超长上下文是卖点（V4 宣称百万 token），但社区实证长程仍"失忆崩人设"（B站 笙说说 2026-08-07）；窗口大 ≠ 记忆可靠，需外部记忆/大纲回注。 |
| 风格模仿 | 中强 | 给足风格例句 + 禁止词表后模仿力强；但容易"模仿到形、漏掉神"，文风漂移出现在长文后段。 |

### 3. 本技能包适配建议

- **提示词详细度：极细（可吃下最长提示词）**。DeepSeek 是国产里指令遵循最强之一，技能包可全量压上：设定库、术语表、禁止项、风格例句、格式要求全部保留，逐条执行。
- **限制力度：强约束清单（重点在"防补设定"）**。对"不得新增任何原作未有的设定/人名/能力"类否定式约束执行较好；但需同时给"可查的设定引用方式"（如先列出引用自哪条档案），否则它倾向自由发挥。
- **防幻觉措施**（该模型最常见幻觉点）：
  - 点1：顺口编新角色/新组织名 → 规则："一切名词必须来自给定档案，若确需新名词先询问，禁止自行命名"。
  - 点2：把 1999 世界观术语泛化成通用英伦/复古词（"暴雨"写成"大洪水"、"重塑之手"写成"教会"）→ 在禁止词表列出易混淆词对。
  - 点3（R1/思考模式）：正文外出现分析性文字 → 规则："只输出正文，禁止任何解释、说明、大纲式标注、括号注"。
- **推荐写作流程：分步（大纲+场景），绝不一口气长文**。社区共识流程：人设档案 → 分幕细纲 → 每场景单独生成 → 逐段回注设定。适合技能包的"场景卡"结构；多场景连写时要求模型先重述设定要点再动笔。
- **温度等参数**（官方文档 api-docs.deepseek.com，2026-08-10 抓取成功）：创意类写作/诗歌创作 **temperature=1.5**；通用对话 1.3；数据抽取/分析 1.0；代码/数学 0.0；默认 1.0。注意 1.5 是"更发散"方向，本技能包强约束仿写（防 OOC）场景建议回落 1.2–1.3；top_p 官方未给专门建议。

## 二、GLM（智谱：GLM-4.6 / GLM-5 / GLM-5.1 / GLM-5.2）

### 1. 模型画像（2026 社区共识）

- 2026 年国产"长任务"代表：GLM-5（2026-02 发布，745B 总参/440B 激活 MoE、200K 上下文）主打"复杂系统 + 长程 Agent"；GLM-5.1（2026-04 前后）社区实测"8 小时长任务不翻车"（B站 御风大世界 2026-04-08）；GLM-5.2（2026-06 发布）主打 Solid 1M 无损上下文 + 长程 Coding Agent。
- 官方自述 GLM-4.6 起"写作能力：在文风、可读性与角色扮演场景中更符合人类偏好"，推荐场景含"内容创作（小说、脚本、文案）"与"虚拟角色（多轮对话中保持语气和行为一致）"（docs.bigmodel.cn，2026-08 抓取）——官方明确把"角色扮演/文风"列为卖点。
- 社区写小说测评：GLM-5.2 发布后多篇正面测试（星月凌云 2026-06-17"GLM5.2小说能力这么强？"、垚和森 2026-06-19、白梦写作小助手 2026-06-22 与 Opus 4.8 对比），但测评者结论普遍是"强，但还不是最强"（最强被指向 Claude 系）。
- 阮一峰（2026-02-12）实测 GLM-5：一项个人任务跑了 2 小时"最后完成，没有乱掉"——长程连贯是 GLM 相对其他国产模型的招牌。
- 社区体感：GLM 文风偏"稳妥/克制"，语感现代化，写复古/晦涩文风需要较强引导；中文自然度在国产第一梯队。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|
| 创作/文笔 | 中强 | 结构与收束能力强，段落逻辑稳；文笔偏"工整"，惊艳度不及巅峰期 DeepSeek V3 与 Claude 系；GLM-5.2 写作评测正面但非碾压（B站 2026-06 多篇）。 |
| 指令遵循 | 强 | 官方与社区均显示结构化指令执行稳定；角色扮演"语气行为一致"是官方卖点；long-horizon 任务不跑偏。 |
| 幻觉控制 | 中 | 无"顺口编名"恶名，但长上下文下细节回注需求仍存在；GLM-5 在 Agent 测试中"缺功能而非架构错"（阮一峰 2026-02），类比创作即"漏细节多于乱编"。 |
| 长文一致性 | 强 | 全家族最强项：200K→1M 上下文 + 长程强化训练；GLM-5.1/5.2 长任务稳定性有官方+社区双证。 |
| 风格模仿 | 中强 | 官方强调文风/可读性/角色扮演偏好优化；模仿"语气"（口癖、冷幽默）比模仿"修辞密度"（繁复长句、意象）更稳。 |

### 3. 本技能包适配建议

- **提示词详细度：适中偏细**。GLM 不需要像 DeepSeek 那样把禁止项铺满，但 1999 设定密集度高，设定库+术语表应保留；可删减"重复强调型"冗余约束（它对长指令忠实度够，且过分冗长会稀释其工整文风）。
- **限制力度：中等**。它偏"稳妥"，自由发挥冲动弱于 DeepSeek，约束清单给到"禁止新增设定 + 风格参考例"即可；重点放在"要求按档案回注"而非大量否定句。
- **防幻觉措施**（该模型最常见问题）：
  - 点1：细节遗漏（漏掉档案中的关键道具/人物在场情况）→ 规则："动笔前列出本场景涉及的档案条目，写完自查是否全部出现"。
  - 点2：文风"工整化"——把 1999 的冷峻/荒诞语句改写成标准书面语 → 提供 2–3 段原文风格例句 + "句式须向例句靠拢，不得规范化改写"。
- **推荐写作流程：分步为主，可尝试"单场景一次长文"**。GLM 是国产里唯一值得试"长场景一次生成"的（长程连贯强）；跨章节仍走"大纲+回注"。
- **温度等参数**：官方文档未给分场景温度表（docs.bigmodel.cn 调用示例用 temperature=1.0，2026-08 抓取）。参照示例与社区经验：创作 1.0–1.2，强仿写场景取 0.9–1.0 更稳。

## 三、Qwen（通义千问：Qwen3 / Qwen3.8-Max 系列）

### 1. 模型画像（2026 社区共识）

- 国产开源生态之王；写小说圈口碑两极分化：长上下文、低成本、Agent 能力强，但"正文文笔"评价不稳，B站测评标题常"意想不到的强/差"并存（星月凌云 2026-08-07《Qwen3.8写小说能力测评》）。
- 产品线节奏：Qwen3.7 后节奏放缓（知乎问题摘要，2026-08-03："前 4 个月几乎月更模型，发布 Qwen3.7 之后足足打磨了两个…"，页面 403 无法读全文，仅摘要）；Qwen3.8-Max 2026-08-03 上线，2.4T 参数，主打编程/长程（qwen.ai 官方 blog）。
- 社区评测语境（B站 2026-07 多篇）：Qwen 属于"规划强于执行"——细纲/世界观构建类任务口碑好，正文直出质量一般；"最会规划的反而最不会写正文"是同期横评主题（AI责编-武行 2026-07-22"35块测了AI御三家写网文"）。
- 千问/通义在长文续写上有工具侧优势（百炼生态、qwen长上下文），适合当"设定管理 + 大纲 + 扩写"主力，当"成稿"主力需谨慎。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|
| 创作/文笔 | 中 | 场景构建、细节丰富度可；文笔偏"流畅但模板化"，情绪层次浅；社区横评中正文直出不占优（B站 2026-07 多篇横评）。 |
| 指令遵循 | 中强 | 结构化指令基本照做；复杂多条件约束（既要文风又要禁令）偶有取舍失衡，需把"最不能违反的项"放最前。 |
| 幻觉控制 | 中 | 世界观类编造不多见，但细节易"想当然"（如默认角色在场、默认时代背景）；需要显式"在场角色清单"。 |
| 长文一致性 | 中 | 长上下文规格高（3.8-Max 官方主打 long-context），但社区未出现"长文不崩"的强口碑；跨章仍建议回注。 |
| 风格模仿 | 中 | 给定风格例句能模仿大面，但"神韵"层（冷幽默、留白）保持力弱于 GLM 与 DeepSeek（配好提示词时）。 |

### 3. 本技能包适配建议

- **提示词详细度：适中**。设定库+术语表保留；避免超长禁止项列表（会稀释执行重点），把规则压缩成"三级：必须做 / 禁止做 / 可选"，重要项靠前。
- **限制力度：中等**。它不擅长"自由发挥编设定"（幻觉不突出），但容易"想当然加戏"（人物、场景默认在场）→ 限制清单聚焦"在场清单与视角锁定"，而非全量否定句。
- **防幻觉措施**（该模型最常见问题）：
  - 点1：想当然地默认角色/道具在场 → 规则：每场景给出"在场角色/道具清单"，要求正文只允许写清单内元素。
  - 点2：视角漂移（从指定视角跳到上帝视角）→ 规则："全篇锁定 X 视角，禁止其他角色内心活动直述"。
- **推荐写作流程：分步**。它最适合"大纲-细纲-分场景"管线；场景正文生成前先让它复述该场景要点。不适合一口气长文直出。
- **温度等参数**：官方未检索到专门温度建议表（阿里云百炼帮助页 404，访问失败）。社区通用做法：创作 0.8–1.0（Qwen 系默认偏低发散），仿写场景 0.7–0.9 更稳；top_p 无官方专门建议。

## 四、MiniMax（abab / M2.5 / M2.7 / M3 / 海螺 / 星野）

### 1. 模型画像（2026 社区共识）

- MiniMax 的 2026 重心在"多模态 + 长程 Agent"：M3（2026-06 前后）主打 Coding、1M 上下文（自研 Sparse Attention，保障 512K 可用）、原生多模态（minimaxi.com 官方页，2026-08 抓取）；音乐/视频（H3、Music 3.0）是强项。
- 文本写作的社区存在感集中在**角色扮演（RP）侧**：海螺 AI 官方定位含"创意写作"（minimaxzh.com），但 B站 社区讨论几乎全是视频生成（H3）与语音；文本写作口碑主要沉淀在星野（角色扮演社区，2024 年巅峰期）与"接入 SillyTavern 酒馆"玩 RP（B站 2026-04-14）。
- 星野侧社区体感（B站 2023-2026 多期）：早期 RP 文笔/氛围在国产里第一梯队（"玩哭了""纯爱结局"），但"风控收紧/改版削弱"是长期槽点（"现在的星野VS以前的星野" 2024-11；"星野难道永远开不了车了吗" 2026-01；"锐评星野最新版本" 2026-07）。
- 结论：MiniMax 文本生成"氛围感/角色感"有底子，但 2026 年官方重心与社区讨论都不在"长篇中文创作"上，适配时按"可用的 RP/短篇创作模型"定位，而非旗舰写作主力。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|

### 3. 本技能包适配建议

- **提示词详细度：适中**。它擅长"氛围"而非"规则执行"，设定库保留但压缩为"关键 20 条"以内；冗长约束会拖垮输出质量。
- **限制力度：中等偏弱**。RP 底子让它更容易进入"角色状态"，但 OOC 风险在情绪高潮段落（容易煽情化/玛丽苏化）；限制清单主打"情感浓度上限 + 角色台词人设校验"。
- **防幻觉措施**（该模型最常见问题）：
  - 点1：情绪加戏（把 1999 的克制哀伤写成大哭大闹）→ 规则："情感表达参照原文角色的克制度，禁止过度抒情/煽情句式"。
  - 点2：设定漂移（角色关系、称谓搞错）→ 场景卡中单独列出"称谓与关系"行，并要求"写作时角色称谓必须与档案一致"。
- **推荐写作流程：分步（短场景+回合式）**。它最像"扮演型"模型，适合对话密集的短场景逐段生成；长文由多段短场景拼接。一次给超长指令反而吃亏。
- **温度等参数**：官方文档未抓取到专门温度建议（platform.minimaxi.com 需 JS，访问失败）。社区通用：创作 0.9–1.1；RP 氛围场景可 1.0 以上发散，强 OOC 控制取 0.8 左右。
