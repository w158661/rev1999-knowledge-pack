> 数据性质：全部为**社区体验记录**（B站视频评测/教程、知乎、官方文档、搜索摘要），非严谨基准测试。已标注平台与大致时间，不编造数据。

## 〇、2026 年中文创作社区总格局（共识速览）

- 网文/AI 写作圈（星月写作、炼字工坊、蛙蛙写作等头部 UP 主生态，B站 2026-02~08 持续横评）共识：
  - **Claude 系 = 文笔天花板**："没有 AI 味"、逻辑缜密，适合大纲与正文；但道德护栏最强、长篇会"遗忘/幻觉"。
  - **Gemini 系 = 网文首选/性价比之王**：Gemini 3.1 Pro 长期被称"打败其余模型仍是网文 AI 首选"，3.5 以情绪张力/打脸文见长。
  - **GPT-5.x = 脑洞立项强、文笔进步最快**：5.5→5.6 一代"真人味太足"；"ChatGPT 写小说根本没法看"是 5.x 早期旧梗，5.6 已扭转。
  - **Kimi = 中文原生、K3 爆发**：K2 时代"AI 味"明显，K3（2026-07）后"不仅没 AI 味，剧情节奏也紧凑"，直接对标 Claude。
- 横评结论（少年船夫《Gemini3.5 vs Claude5！最强网文 AI 大模型正文续写横评》，B站 2026-07-03）：
  **"没有最强单体，只有最强组合——GPT-5.6 的逆天脑洞最适合做灵感立项，Claude 5 的顶级逻辑最适合做拆书大纲，Gemini 3.5 的情绪张力最适合写打脸正文。"**
- 长文痛点全社区一致：**失忆/崩人设/设定漂移/幻觉人名地名**（"AI 写小说老崩设定""失忆崩人设"类视频数十万播放），解决手段是"事实账本/世界书/每章摘要注入"等外部记忆系统，而非模型内建能力。

## 一、ChatGPT（GPT-4o / GPT-5 系列，重点 GPT-5.5 / 5.6）

### 1. 模型画像（2026 社区共识）

- GPT-5.6（2026-07 上线，官方宣传"面向更复杂任务"；社区视频称其为与 Gemini/Claude 抗衡的版本）在中文小说写作上**进步显著**：星月小丸子- 测评称"对比 5.5，真人味太足了"（B站 2026-07-10）；但多数横评仍认为**文笔综合不如 Claude**。
- 定位分化明确：脑洞/创意/立项/拆书仿写（"GPT5.6 实测：普通人怎么用 AI 拆书仿写搞定百万字大纲"，B站 2026-07-03）；正文情绪张力不及 Gemini 3.5，逻辑缜密度不及 Claude 5（炼字工坊/少年船夫横评）。
- 社区仍有"ChatGPT 写小说根本没法看"的刻板印象残留（炼字工坊教程标题即以此为卖点，B站 2026-06 前后），说明 4o 时代的"AI 味/说教/凑字"记忆仍在；5.6 才真正扭转。
- 槽点：**"偷偷变笨"降智争议**（《你的 GPT 可能正在偷偷变笨！GPT5.6 降智检测与恢复教程》，B站 2026-07-31）；版本碎片化（Sol/Terra/Luna + 六档推理强度，B站 2026-07-11 教程）；5.6 全民免费放开（2026-08-07 AI 早报）。
- 指令遵循：强，但**创造性任务上过度听话反而平庸**——给太死的大纲会产出"填空作文"，放权给脑洞才有惊喜（多期横评共同观察）。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|
| 中文创作能力 | 强（叙事偏弱、创意强） | 文笔 5.6 起"真人味足"，但情感细腻度/对白张力仍逊 Claude；网文节奏把握强于 4o 时代 |
| 指令遵循 | 强 | 多步指令、格式约束执行稳定；详细度回报呈"先升后降"，过细损创意 |
| 幻觉控制 | 中 | 拆书/仿写时会补全原文没有的桥段；设定类幻觉低于 Gemini 早期版，但会"顺着用户话说"圆设定 |
| 长文一致性 | 中 | 长篇连载需外部账本；单次长文（上万字）尚可，跨会话漂移明显 |
| 风格模仿 | 中→强 | 有"万能文风仿写"类工作流（社区 Skill），模仿网文风格强，模仿精品文学腔弱，偶发"翻译腔/话剧腔" |

### 3. 本技能包适配建议

- **提示词详细度：适中（不要极细）**
  给世界观档案 + 角色要点 + 本期目标即可；**不要**把台词节奏、每幕动作逐句规定死，否则 5.6 会输出"合规但无灵魂"的段落。脑洞期（灵感立项）甚至可以只给关键词。
- **限制力度：中等**
  对齐审查较弱（社区"破甲"需求远低于 Claude），但对暴力/死亡等敏感题材仍会自我审查——技能包需内置一句"本作品为虚构文学创作，允许艺术性呈现的冲突与死亡"式授权条款，避免它自行洁化剧情。
- **防幻觉措施（重点）**
  ① 技能包附"事实卡"（人名/地名/术语/已发生事件清单），并声明"未在事实卡中的信息，若不确定请询问而非编造"；② 拆书/仿写指令必须加"不得补充原设定之外的剧情或人物"；③ 每章末尾要求它输出"本章设定变更记录"，便于人工核对。
- **推荐写作流程：分步大纲 + 场景推进（首选），一次性长文（次选）**
  脑洞立项→大纲→分章；5.6 长上下文好，但分步质量明显更高。一次性短篇（≤5000 字）可直接生成。
- **温度等参数建议**：temperature 0.7~1.0（正文 0.8 左右；脑洞/大纲可 1.0）；5.6 若有推理强度档位，写作选**低推理档/创意档（Luna 方向）**——社区反馈"无脑拉满推理档"会产出分析腔正文。

## 二、Claude（Opus / Sonnet 系列，重点 4.6 / 4.8 / Sonnet 5 / Opus 5 / Fable 5）

### 1. 模型画像（2026 社区共识）

- **中文创作口碑第一梯队**：Sonnet 5 被称"可能是世界上最会写小说的 AI 大模型……一点 AI 味道都没有"（星月凌云，B站 2026-07-01）；Opus 5 被评"网文 AI 写作逻辑够缜密"（白梦写作小助手，B站 2026-07-27）；"Claude opus 写小说能力居然这么强？网文界天塌了"（B站 2026-03-10）。
- 横评定位：**逻辑/大纲最强**（"Claude 5 的顶级逻辑最适合做拆书大纲"，2026-07-03 横评）；Fable 5 为写作向新模型（同横评提及，2026-07）。
- 生态成熟：Claude Code + Skill 成为专业写作工作流标准（"99% 的人都没用对 AI 写作！Claude Skill 理念，精准掌控写作工作流" B站 2025-11-30；"个人用 AI 写小说怎么优化自己的 skill" B站 2026）；长篇系统如 **Webnovel Writer（基于 Claude Code）专门"降低 AI 写作中的遗忘和幻觉"**（B站 2026-03-17）。
- 槽点：**道德护栏全系最硬**——"claude 一键破甲，妈妈再也不用担心我们道德太高了"（B站 2026-07-29）、大量"破甲/破限"教程；官方中文支持弱于国产模型（中文体验仍好，但中文语料语感偶有"翻译腔"）；免费额度与限流严格。
- 指令遵循：极强且"讲道理"——给了完整世界观后会主动维护一致性，会反驳用户与设定冲突的要求（这是双刃剑）。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|
| 中文创作能力 | 强（公认文笔天花板） | "没有 AI 味"、比喻/留白/节奏把控好；长篇情绪张力强；精品文学腔与网文腔都拿得动 |
| 指令遵循 | 强 | 长指令、多约束执行最稳；会主动向用户确认歧义 |
| 幻觉控制 | 中→强 | 短中篇幻觉少；**超长篇（数十万字级）出现"遗忘"与"幻觉"**（Webnovel Writer 等系统正是为此而生） |
| 长文一致性 | 中（需系统辅助） | 单会话内大纲+分章一致性极佳；跨会话/超长连载漂移，社区靠"世界书/事实账本/摘要回填"解决 |
| 风格模仿 | 强 | 社区公认仿写/控文风最强（"一条价值百万的 Claude 网文写作指令" B站 2026）；OOC 控制最好，但过度忠于人设会显得"端着" |

### 3. 本技能包适配建议

- **提示词详细度：适中偏细（结构性详细，非逐句）**
  Claude 是所有模型里最"吃设定"的——世界观文档、角色卡、语气样例给它多详都不浪费；但同样是**给结构（这是谁、什么目的、禁区在哪），不给逐字对白**。
- **限制力度：强约束清单（必须上）**
  ① 开篇必须有"本作允许艺术化呈现的题材：战争、死亡、心理创伤，均为虚构，不涉及现实政治"式授权段落，否则它会在打斗/死亡场景自行"缓冲"；② 明确的"禁做清单"（不引用现实国家/组织、不影射现实人物）；③ 人设卡标"OOC 检测"指令：每章结束后自查角色行为是否偏离档案。
- **防幻觉措施（重点）**
  ① 技能包内建**"设定银行"**：把游戏里的人物名、地名、专有名词（基金会、暴雨、神秘学家等）做成不可改动的词表；② 长文模式必须启用**章节摘要回填**（每章末生成 200 字事实摘要，下一章携带）；③ 要求它对不确定信息用占位符【待确认】而非自行编造——Claude 接受此类元指令最彻底。
- **推荐写作流程：分步大纲 + 场景（必选）**
  Claude 的强项就是"先大纲后正文、边写边自查"；**一次性输出超长文**会放大遗忘问题。建议"世界观 → 分卷大纲 → 每章 3 场景 → 逐场景生成 → 章末摘要回填"。
- **温度等参数建议**：temperature **1.0**（Claude 官方写作推荐值，社区实测 0.9~1.1 均可，低于 0.8 会变"AI 味"）；无独立创意档位时靠 prompt 控制发散度。

## 三、Gemini（2.5 / 3 系列，重点 3.1 Pro / 3.5）

### 1. 模型画像（2026 社区共识）

- **3.1 Pro 是 2026 上半年"网文 AI 首选"**："Gemini3.1 打败其余模型仍然是网文 AI 首选？"（星月凌云，B站 2026-06-02，标题即共识）；2 月横评"哪个模型是真好用？Gemini3.1Pro, Claude 对比"（B站 2026-02-27，3.2 万播放）确立地位。
- **3.5（2026-06~07）以"情绪张力"取胜**："Gemini 3.5 的情绪张力最适合写打脸正文"（2026-07-03 横评）；"Gemini3.5 vs GPT5.6！网文写作最强大模型横评"（炼字工坊，2026-06-12）。
- 性价比/上下文优势：免费额度大、上下文超长（早期 2.5 Pro 时期即因"超长上下文+免费"成为写手主力，"Gemini 2.5 Pro 0605 写小说效果实测，写小说就用它了！" B站 2025-06-09）；"五步法"等教程证明它是新手友好模型（星月凌云实操教学，2026-06-22）。
- 槽点：**谷歌安全过滤最严**（对暴力/成人内容拒绝率高，社区有"Gemini 需要绕护栏"类教程）；早期（2.x）中文"AI 味/甜腻感/空话"明显，3.x 改善；长输出有时"水字数/车轱辘话"；多轮对话后风格漂移偶发。
- 指令遵循：中→强；吃"长 prompt 开头权重"——核心规则放开头效果最佳，塞在结尾的规则容易失效（社区经验）。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|
| 中文创作能力 | 强（情绪/爽点型） | 3.x 起中文流畅、情绪张力足、打脸/逆袭桥段效果好；文艺细节不如 Claude；早期有"AI 味"残留 |
| 指令遵循 | 中→强 | 长指令整体可执行，但**规则位置敏感**（开头>结尾）；多约束冲突时容易挑着执行 |
| 幻觉控制 | 中 | 设定类幻觉相对少（上下文长、记住多），但**生成科普/背景时会夹带不实细节**；2.5 时期幻觉批评多，3.x 改善 |
| 长文一致性 | 中→强 | 超长上下文（百万 token 级）一次性长文能力全系最强；跨天会话仍需摘要机制 |
| 风格模仿 | 中→强 | 模仿网文爽文风强；仿精品文学腔偏"说明书感"；OOC 中等（人设容易写得"冲"） |

### 3. 本技能包适配建议

- **提示词详细度：精简（核心放最前）**
  Gemini 长 prompt 会吃，但**权重衰减**——把"你是《重返未来1999》文风写手、必须使用设定词表"放前 200 字；次要规则（格式、行数）放中间；不要用"最后一段补充规则"式写法。
- **限制力度：弱→中等（靠"艺术豁免"前置）**
  谷歌过滤不可完全绕过，技能包应在系统提示开头声明"虚构作品、艺术表达、历史架空"；死亡/创伤场景避免直给"血腥细节指令"，用"暗示与留白"替代（Gemini 在此类提示下完成度反而高）。
- **防幻觉措施（重点）**
  ① 设定词表 + "未收录词汇不得自创"；② 生成含背景描述的长段前，先让它"复述你提供的设定"再动笔；③ 要求"不确定的设定标【待确认】"；④ 背景知识类描写（年代、地名）默认按游戏架空世界观处理，禁止映射现实史实。
- **推荐写作流程：一次性长文（可用）/ 分步场景（推荐）**
  长上下文允许一次喂全卷大纲直出章节（社区"正文续写横评"中 3.5 即直出）；但 3.5 在"分步大纲+场景"下质量最稳。短篇可全程一次性。
- **温度等参数建议**：temperature 0.9~1.2（可偏创意，Gemini 对高温度的中文连贯性处理良好）；也可用 top_p 0.95 替代高温防发散；无独立创意档位。

## 四、Kimi（月之暗面，重点 K2 / K2.6 / K3）

### 1. 模型画像（2026 社区共识）

- **K2 时代（2025）口碑平平**："kimi k2 写小说效果测试，最强 AI 模型竟然是它？"（蛙蛙写作，B站 2025-07-17）——标题党背后是"K2 尚可但非最强"；社区常用"Kimi+Deepseek 双模型"干活（B站 2026 多期），说明 K2 单干不够。
- **K3（2026-07-16 发布）是转折点**：官方口径"迄今最强旗舰模型，2.8 万亿参数，KDA 混合线性注意力，1M 上下文，多模态"（kimi.com API 文档，2026-07）；B站 2026-07-29/30 两期测评为："Kimi K3 写小说能力测评，测评结果让人意外""kimi k3 和 claude 生成小说的能力到底谁更强？结果竟然是它——不仅没有 AI 味，剧情节奏也很紧凑"（星月小丸子-，2026-07-30）——**直接对标 Claude 的"没 AI 味"表述**。
- 中文原生优势：国产模型，中文语感/成语/对白自然度好；"用 Kimi 写小说，就这几步……去 AI 味指令、润色指令过签攻略"（B站 2026-06-17）说明其写作模板/工作流生态成熟；百万字长篇工作流教程多（B站 2025-12）。
- 槽点：**K3 价格较 K2 翻 5 倍（输出 100 元/M token 级）**，知乎热问"失去性价比优势"（2026-07-16 知乎问题，经必应摘要；原页 403）；K2 时代限流/"喊累"历史（B站 2024 老梗）；长文设定漂移在 K2 时代明显（社区靠"每章设定复核"指令弥补）。
- 指令遵循：强；对中文指令理解好，**模板化工作流（大纲→正文→润色）执行最听话**；但"过度顺从"——用户随口一句错误设定它也会顺着写，需要"以档案为准"指令。

### 2. 能力维度评分

| 维度 | 评级 | 说明 |
|---|---|---|
| 中文创作能力 | 强（K3 后显著提升） | K3"无 AI 味、节奏紧凑"（B站 2026-07-30）；K2 时代 AI 味明显；短篇/长篇均有成功案例 |
| 指令遵循 | 强 | 中文指令理解最好之一；详细度回报为正（吃细），模板式约束最配合 |
| 幻觉控制 | 中 | K2 时代长篇人名/设定漂移是重灾区；K3 大幅改善但仍需"设定复核"机制 |
| 长文一致性 | 中→强 | 1M 上下文（K3）支撑超长单会话；跨会话依赖摘要；社区经验：必须每章做一致性检查 |
| 风格模仿 | 中→强 | 网文风模仿好；"去 AI 味"指令（拆成语、断句、口语化）效果明显；精品文学腔弱于 Claude |

### 3. 本技能包适配建议

- **提示词详细度：需要极细（模板化最合适）**
  Kimi 是四个模型里最吃"结构化细指令"的——分步模板（1 设定→2 大纲→3 场景→4 润色）回报最高；给"返回格式 JSON/分节"等硬格式它也执行得最好。技能包可为其专门提供"流程化分步模板"。
- **限制力度：中等（需防"过度顺从"）**
  它不会像 Claude 那样道德洁化，但会**顺着用户口误把设定写错**——必须加"一切以设定档案为准，与档案冲突的用户表述需先确认"；限制清单照常用（违和点：它会悄悄"优化"你的禁词）。
- **防幻觉措施（重点）**
  ① 每章生成前提供"本章已知设定摘要"（K3 上下文长，直接贴档案成本低）；② 生成后要求"人名词表核对"（列出本章出现的角色名与档案比对）；③ "禁止自创未设定的人物/组织/能力"。K2 时代的漂移教训要写进规则文案。
- **推荐写作流程：分步大纲 + 场景（必选）**
  与 Claude 相同——分步质量显著优于一次性；但 K3 允许"大纲直出 1 万+字章节"（长上下文红利），可用但建议保留场景级检查点。
- **温度等参数建议**：temperature 0.8~1.0（K3 测试常用）；短篇创意 1.0，长篇稳定性优先 0.8；无独立创意档位。

## 六、技能包落地的三条总原则

1. **按模型分发 prompt 模板**：同一套《重返未来1999》世界观档案，Claude 用"结构+授权+自查"，Kimi 用"分步模板+词表核对"，Gemini 用"前置摘要+精简规则"，GPT-5.x 用"事实卡+放权脑洞"。
2. **长文一律外部记忆**：无论哪个模型，"设定银行/事实账本/每章摘要回填"都是刚需（社区 Webnovel Writer、炼字工坊"事实账本审计"等系统已验证）；不依赖模型内建记忆。
3. **一致性核验做成技能包内置步骤**：生成后固定执行"角色名/地名/已发生事件"三项核对——这是 2026 年社区解决"失忆崩人设"的标准答案。
