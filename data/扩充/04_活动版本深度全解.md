## 〇、总览：版本节奏与活动体系

### 0.1 版本周期规律（依据：活动列表/活动简介）

- 一个版本一般为 **42天** 刷新，少数为 **21天**（3.6版本「人们向何处去」即首次21天特殊版本）；另有 2.4/2.7 为35天、3.1 为41天、3.3 为40天、3.4 为42天、3.5 为35天。
- 1.4版本起，每个版本推出后同步推出对应成就套组（旅行手册）。
- 每年三次重大节庆：**春节**（度朔节，新春特别版本）、**周年庆**（6月，多为主线剧情、代表大版本终章）、**箱中巡游**（9-10月半周年庆典）。
- 联动版本以 S 系列编号：S01 刺客信条联动、S02 原子之心联动。

### 0.2 版本必有内容（依据：活动列表/活动简介）

| 内容 | 说明 |
|---|---|
| 一期主题活动 | 该版本活动剧情或主线故事，含故事模式+探索模式（探索模式无需体力）；主线版本时任意渠道消耗细胞活性按 1:10 获得货币，概率掉落苦目软糖 |
| 两期角色剧情 | 版本两个新6星角色的个人剧情，分上下半推出，由考察（体验新角色战斗）/剧情/小游戏组成；部分配音 |
| 一期轶事 | 往期角色剧情，叙事轻松多变、可有多个角色客串；3.0版本起由文字演出与多结局"演绎篇"形式展出；结束后立即上架【轶事】栏目 |
| 两期签到活动 | 一般分上下两篇各7日，共送独一律×14；重大庆典（限定角色）签到满20日共送独一律×20 |
| 一期预热活动 | 上版本末开放，预告下版本 |
| 一期H5活动 | 上版本末开放，网页小游戏/资讯合集 |

### 0.3 版本可能内容

- 一期限时季度挑战：系列有 UTTU闪烁集会、UTTU聚光专栏、趋光性研究（完成后可获得衣着等奖励；活动衣着、头像奖励在 **14个版本后** 随新版本更新限时上架「旅程拾遗」整个版本）。
- 一期鬃毛邮报；一期双倍活动（双重解析/双重谐振/双重熔铸，共20次、每日最多4次）；一期限时重映（自1.6版本起，任务重置、商店限购数重置，重复获得限定物品转化为"一小束光"）；不定数目大型活动（结束后成就无法补拿；部分玩法后续版本升级重开但记录重置）。

### 0.4 常驻内容（依据：活动列表）

入场常驻：人工梦游、局外演绎（黄昏的音序）、雨中悬想、第三扇门。另有 不休荒原、前线观察室、鬃毛邮报（周期挑战）、焦点闪回（周期挑战）。**雨前漫游指南** 自3.5版本起常驻；**无声综合征** 自3.8版本起常驻（含"声源修葺处-第Ⅲ期"）。**狂想与解构** 自2.3版本起为常驻养成配套活动。

## 六、UTTU 专题（依据：data/UTTU/ 41个文件）

### 6.1 UTTU 是什么

- **《UTTU》是游戏世界观中的神秘学界知名杂志**（虚构刊物）。字车兑换码页中"UTTU"码的含义即标注为"神秘学杂志名"。
- **UTTU闪烁集会 / UTTU聚光专栏**是游戏内"限时季度挑战"活动的两个系列：通过挑战特定战斗关卡，获取并携带"名人卡"获得加成效果（不同阶位关卡有差异化名人卡；同品牌名人卡可合并升级）；活动页面含"市场货架/市场杂货"兑换区（使用 UTTU购物票据）与"UTTU谜题/UTTU新谜题"（消耗 UTTU积分）。完成挑战可获得衣着、头像等奖励（活动衣着/头像在14个版本后随版本更新限时上架「旅程拾遗」）。
- 官方另有现实联动：**闪魂 Shining Soul 联动商品"UTTU烁光专栏二期典藏卡"**及配套H5活动「火彩之约专题采访」。
- 数据包内文件构成：7个聚光专栏页 + 3个分章页（亡灵欢歌的恒常的配方/墙的里侧/花与歌）+ 7个闪烁集会页 + 1个闪烁集会总览页 + 14个购物票据页 + 6个积分页 + 2个采风巡行页 + 1个烁光专栏H5页 = 41个文件。
