## 二、命令可用性测试

测试环境：Windows PowerShell 5.1，工作目录 `rev1999-pack/`，前置 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`（必须，否则中文输出乱码）。

| 命令 | 结果 |
|---|---|
| `powershell -ExecutionPolicy Bypass -File skills\rev1999\scripts\query.ps1 "星锑" character` | ✓ 正常。三段分层输出（角色百科 / 扩充卷(权威) / 雨前精编(权威)），含 06_角色档案全量 与 雨前精编/04 命中 |
| `... "暴雨" world` | ✓ 正常。知识文档/扩充卷(深度)/雨前精编(权威) 三源命中，退出码 0 |
| `... "7TH-21" story` | ✓ 正常。扩充卷(深度) 命中 01_主线剧情深度全解 多条 |
| `... "黄昏的音序" all` | ✗ 部分失效。只命中 skill_00 索引 1 条，扩充/30_A 的 8 处命中全部缺失 |
| `... "卡邦克鲁" all`（复验） | ✗ 确认 bug：扩充/32 有 18 处命中，all 模式一条都不显示 |

**Bug 定位**：`query.ps1` 第 95 行 `Search-In @("$Base\雨前精编", "$Base\扩充")` 把**目录路径**传给 `Select-String -Path`，在 PowerShell 5.1 下目录不可作为路径直接匹配，且脚本第 11 行 `$ErrorActionPreference = "SilentlyContinue"` 将错误吞掉 → 静默零命中。character/world/story/system/event 模式全部使用显式文件路径，均正常。附带问题：脚本第 15 行数据根推导 `..\..\..` 从 `skills/rev1999/scripts/` 上溯 3 级后接 `\data`，当前包布局下验证有效。

## 三、测评结论

### 覆盖度评分

- **6 问全部定位成功（6/6）**，平均定位步数 **1.67 步**（1 步直达：b、e；2 步：a、c、d、f）。
- 关卡/BOSS 类问题（c、d）与系统掉落类（f）虽然能查到，但依赖 grep 试错而非文档索引指引，**检索体系引导力弱于内容覆盖度**。
- 深度内容质量高：28_B 含 BOSS 名单、30_A 含 185 关全表、04 含 3.9 版本情报，雨前精编 04 对官方留白有显式提醒。

### 问题清单

1. **主 SKILL.md 知识文档索引漏列 7 个文件**：skill_00/09/10/11/15/16/17 未入索引，其中 skill_16 登场索引（本测试问 a 的关键路径）在快速查询指南中完全无入口。
2. **扩充卷索引只给批次不给内容划分**：28_A~D、29_A~F、30_A~D、31_A~B 均未注明"哪卷含哪章/哪活动"，关卡类问题必须全文 grep。
3. **query.ps1 的 all 模式失效**（扩充/雨前精编目录路径 bug，静默失败），且 `SilentlyContinue` 掩盖错误，用户无感知。
4. **数量与索引文案漂移**：SKILL.md 与 skill_00 写"扩充卷 50 个文件"，实际 51 个；扩充索引漏列 `25_人工梦游深度全解_浅眠深眠.md`；29 卷实际 A~F 六批而索引写 A~E 五批；rev1999-query 目录结构写"扩充/(31个)"与实际 51 个严重不符。
5. **skill_00 新增辅助卷清单无文件名**（只写"第十六卷（角色登场索引）"），agent 需多一步 glob 才能定位 skill_16。
6. **缺关卡查询入口**：快速查询指南没有"关卡/BOSS/掉落"行，`扩充/34_战斗关卡汇总索引.md`（现成的全局关卡入口，含前缀映射/敌人/掉落）未被设为关卡类问题的首选入口。
7. **缺快速索引文件**：没有一份"扩充卷子文件内容划分速查表"（如：28_B=第5~8章、30_A=黄昏的音序…），关卡定位全靠搜索。

### 检索体系改进建议（8 条）

1. **主 SKILL.md 知识文档索引补全**：补列 skill_00/09/10/11/15/16/17 及一句话用途，快速查询指南"角色资料"行追加"登场章节 → skill_16"。
2. **新增关卡查询入口行**：快速查询指南增加"关卡/BOSS/掉落"行 → 首选 `扩充/34_战斗关卡汇总索引.md`，再按 28/29/30/31/32 对应批次下钻。
3. **修复 query.ps1 all 模式**：`Search-In` 内对目录参数先 `Get-ChildItem` 展开文件清单（或改用 `-Path "$dir\*"` 通配），并将 `$ErrorActionPreference` 改为按需处理而非全局静默。
4. **扩充卷新增"00_内容划分速查"**：逐卷列出子文件覆盖范围（A~D 各含哪章/哪活动），并写进主 SKILL.md 扩充索引与 skill_00。
5. **同步修正索引数字**：扩充 50→51、29 卷 A~E→A~F、rev1999-query 目录结构"31 个"改为实时值，并注明 25 号卷。
6. **skill_00 辅助卷清单补文件名**：第十六卷→`skill_16_角色登场索引.md`，第十七卷→`skill_17_角色签到剧场.md`，其余同理。
7. **query.ps1 增加关卡参数类型**：新增 `stage`/`drop` 类型（检索 28~34 号卷），或让 all 模式默认覆盖全部扩充卷；并输出命中文件数统计，避免"静默零命中"。
8. **词表互见（f 问教训）**：在 34 汇总索引的"魔精系"条目与 32 §2.3 之间补互链（"掉落规律见 32§2.3 / 敌人分布见 34"），并让"魔精公司"一词可直达 08 附章，减少换词检索。
