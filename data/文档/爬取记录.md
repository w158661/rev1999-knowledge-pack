## 5. 注意事项

### 5.1 MediaWiki API 限制

- 部分页面内容通过 JavaScript 动态加载，MediaWiki API 的 `action=parse` 无法获取这些动态内容
- 签到记录页面使用了 Widget 扩展和 JS 动态渲染，API 返回的 HTML 中缺少实际内容，仅能获取到原始 JSON 数据

### 5.2 Tabber 组件

- 部分页面使用了 tabber 多标签页组件，API 返回的内容中所有标签页的内容会合并在一起，需要额外解析分离

### 5.3 Cloudflare 防护

- 站点启用了 Cloudflare 防护，直接请求可能被拦截
- 需要设置合适的 User-Agent 头
- 高频请求会触发频率限制，需要控制请求间隔（建议 1-2 秒以上）
- 部分情况下可能需要浏览器指纹模拟

### 5.4 数据完整性

- 剧情文本（主线/支线/小径）以纯文本形式保存，保留了原始内容结构
- 角色数据以 `.md` 格式保存，包含角色属性、技能、背景等完整信息
- 衣着数据和部分系统数据以 JSON 格式保存，保持结构化便于后续处理
- 部分页面（如 `content.html`）保存的是渲染后的 HTML 内容
- 征集和沙盘解构目录为空，相关页面尚未爬取
